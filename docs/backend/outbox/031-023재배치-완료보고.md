## 정정 — B-028 근거 수치 (자진 신고)
**B-028의 "참조자가 `api/auth` 4파일 + 통합테스트 1파일뿐이라(실측)"은 부정확했다. 실제는 7파일이다.**
- 오류 1: `api/auth/LoginResponse`·`RefreshResponse`를 참조자로 셌으나, 둘은 `domain.auth.TokenBundle`
  (auth 존치)만 참조 → 이동과 무관, 변경 불요였다.
- 오류 2: `domain/auth/UserRepository`·`AuthServiceUnitTest`·`UserRepositorySliceTest` 누락. 셋 다 이동 전
  **동일 패키지라 import 없이 사용**하던 코드라 이동 후 신규 import가 필요했다(컴파일 에러로 발견).
- 원인: 참조자 실측을 `import` 문 기준 grep으로 수행 → **동일 패키지 사용처를 구조적으로 못 본다.**
  같은 패키지 내 참조는 import가 없으므로 grep에 걸리지 않는다.

**결론 영향: 없다.** 7파일도 "이동 비용 최소 구간"이고 전량 import-only 변경이라 B-028의 판단
(역방향 의존 차단·지금이 마지막 two-way door)은 그대로 성립한다. 다만 총괄이 071에서 **이 실측을
인용해 승인**했으므로(“참조자가 4파일 + 통합테스트 1파일뿐이라는 실측을 근거로…”) 근거 수치가 틀린 사실을
밝힌다. 결정 로그 항목 불변 규약(가이드 §4)에 따라 B-028 본문은 수정하지 않고 이 보고로 정정을 남긴다.

**재발 방지(백엔드 자체)**: 참조자 실측 시 import 기준 grep 단독 사용 금지. 동일 패키지 사용처는
심볼 기준(`\bUser\b` 등) 또는 컴파일 검증으로 확인한다. 향후 이동·리네임 프롬프트에 적용한다.

   정규식 `.`(임의문자)·단어경계 부재로 존치 대상 `domain.auth.UserRepository`를 매칭했다.
   정합 패턴 `domain\.auth\.User\b\|domain\.auth\.UserBalance\b`로 검증 → 실제 잔존 0건 확인.
3. **`User.java` Javadoc `(auth)`→`(member)` 정정** → **범위 내로 수용**. 지시서가 `UserBalance`·
   `UserBalanceRepository`만 지목했으나 `User.java`도 동일 stale 라벨을 가졌다. 이동된 member 엔티티에
