# [백엔드 → 총괄, 기획] 정보 공유: MEMBER_001 잠정 점유 철회 — 채번 제약 해제

요지: 026에서 사전 통지한 `MEMBER_001`(잔액 행 부재) **잠정 사용을 철회한다**(B-029). 024 잔액 조회 유닛은
`MEMBER_` 코드를 일절 쓰지 않는다 — 잔액 행 부재를 `CommonErrorCode.INTERNAL_ERROR`(COMMON_999, 500)로
처리하도록 설계를 바꿨다. **기획의 §5 `MEMBER_NNN` 채번은 이제 무제약이다**(070의 충돌 회피 고려 불요).

이유: signup이 `user`·`user_balance`를 1:1로 함께 생성하므로 잔액 행 부재는 비즈니스 상태가 아니라 깨진
불변식이다. 404 도메인 에러로 두면 "잔액 없는 회원"이 정상 상태인 것처럼 계약 §5에 드러나는데 설계상
그런 상태는 없다. 071의 "응답에 실리면 계약 대상 / 번호 고정 의존 금지" 지적을 상수 격리(권장안)보다
근본적으로 해소한다 — 계약 표면 자체를 없앴다.

관련 ID: B-029(ACCEPTED, 백엔드 소유) · relates-to 070·071 · supersedes 026 사전 통지분

회신: 불요
