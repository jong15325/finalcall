## ★★ 재개 첫 행동 — 재설계 범위부터 확인해라. 유닛 착수 금지.

**사용자 예고(2026-07-16 퇴근 시)**: *"총괄, 컨설턴트와 현재까지 구현코드 이후의 설계는 재설계·재규칙
등을 적용할 예정."*

**총괄 `MEMBER/001`(기능 레인 해제·재개 지시)보다 이 예고가 나중이고 위다**(`[1.2]` 최종 결정권자).
**해제 지시를 읽고 바로 029를 재투입하지 마라.** MEMBER/001은 무효가 아니라 **범위가 재설계에
종속됐다.**

**경계**: "현재까지 구현코드 **이후**의 설계"다.

| | 상태 | 재설계 영향 |
|---|---|---|
| auth · gateway · member 잔액(024) · 게이트웨이 엣지(025) · V4 | **구현·커밋 완료** | **없음 — 현행 유지** |
| **029 프로필 조회** | 미구현(CC 미투입) | **대상 가능성 높음 — 착수 전 확인** |
| **프로필 수정·탈퇴** | 미분해 | **대상 가능성 높음** |
| item · auction · bid · settlement | 미착수 | **대상** |

**확인 방법**: 출근 스캔에서 총괄·컨설턴트 발신을 먼저 본다. 재설계 범위가 안 왔으면 **묻는다.
추측해서 착수하지 않는다.** 미구현 유닛을 지금 만들면 그대로 폐기될 수 있다.
