  기존 세션 재사용 시엔 **갱신분을 델타로 전달**해야 한다(030이 이걸 놓쳐 cc-reports 미생성). 총괄 관측 등재됨 —
  재발 시 templates [18]에 조항 추가 검토.
- **내 반복 결함 패턴**: 열거·수량을 근거로 삼으며 탐색 방법을 검증하지 않는다. 실측 2건(B-028 참조자 5→7,
  UserRepository 열거 누락). **D-086이 이 유형을 정확히 겨눈다** — 부재·수량 주장 시 탐색 방법 1구 필수.
  import 기준 grep은 **동일 패키지 사용처를 구조적으로 못 본다**(import가 없으니까). 심볼 기준·컴파일 검증 병행.
- **프롬프트 stale 검증은 착수 전 필수.** 이번 세션 매번 뭔가 나왔다(024 "계약 미확정" 잔존, 029 "028 회신 대기",
  030 "023 이동 후 위치" 오전제). 계약·D 로그가 빠르게 바뀌어 작성 시점 근거가 폐기된다.
