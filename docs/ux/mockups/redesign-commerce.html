④ 샘플 아이템 카드 — 부분 게임차용 시연

깨끗한 커머스 카드에 게임이 드러나는 유일한 창: 검정 아트 슬롯 + element 배지. 나머지 정보(가격·판매자·상태)는 전부 커머스 크롬.

게임 아트 슬롯 · docs/game_ui 매핑 물 속성
서리한 롱소드
Lv. 7·경매
현재 최고가 1,280,000G
판매자 달빛상인 ⏱ 04:12
이원 구조. 위 카드에서 게임색(element)과 검정 슬롯은 아트 영역 + 속성 배지에만 있습니다. 가격·판매자·상태 칩·카운트다운은 전부 커머스 토큰(near-black·의미색)입니다.
게임 차용 허용 금지
element 속성 배지버튼·탭·인풋 색
아이템 카드 아트 슬롯(검정)페이지·모달 배경
아이템 필터 element 칩본문 텍스트·링크·내비

element색은 흰 배경 위 텍스트로 쓰면 무너지므로(water 2.4:1) 소프트 틴트 배경 + near-black 라벨 + solid 도트 패턴을 씁니다.
