  • 낙찰 대금은 정산까지 보관됩니다

    구매 대금은 곧장 판매자에게 가지 않고 정산 단계에서 옮겨집니다. 취소·유찰이면 홀드된 금액이 그대로 돌아옵니다.

Retry-After 초를 그대로 카운트다운으로 노출하고 그동안 트리거 버튼을 잠근다(§5.6). 숫자는 tabular-nums라 30→9 로 자릿수가 줄어도 문장이 밀리지 않는다 — 이 카운트다운은 실제로 돌고 있으니 눈으로 확인할 수 있다. 카피는 사용자 잘못이 아니라 "대기"임을 말한다.

가입하신 주소로 인증 메일을 보냈습니다. 메일의 링크를 열면 인증이 끝납니다. 메일이 오지 않았다면 스팸함을 확인해 주세요.

이 상태는 아직 구현 대상이 아니다. 계약 §2 에 이메일 필드·인증 엔드포인트가 없으므로 화면을 만들지 않았고, 여기서 확인하는 것은 하나뿐이다 — 성공 배너가 제목 1줄 + 본문 3줄 + 액션 버튼까지 수용해도 폼 비례가 무너지지 않는가. 배너는 고정 높이가 아니라 콘텐츠 높이를 따르고 카드 상단에 붙으므로, 길어지면 폼이 아래로 밀릴 뿐 레이아웃이 깨지지 않는다. 즉 별도 "인증 메일 발송 안내" 화면 없이 이 배너만으로도 도입 가능하다(별도 화면을 둘지는 도입 시 결정).
