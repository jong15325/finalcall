FC-190 · 배송 상태 UI 디자인 게이트 목업 (승인 전 · 실구현 아님)
구매/낙찰 아이템의 게임 배송 상태를 인벤토리 카드와 거래내역 항목에 배지로 얹었다. 데이터원 = GET /me/deliveries (api-contract §4.6). 기존 인벤/주문 응답 형상은 불변이고, itemInstancePublicId 로 교차 조회한다. 상태 3표현: 배송중(PENDING/CLAIMED/DEFERRED) · 게임 도착(APPLIED) · 문제(FAILED). 팔레트 = index.css 정본(navy/gold/orange).
