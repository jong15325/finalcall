댓글 액션 배치 재정렬: 현재 vs 제안 (웹)

FC-215 디자인 게이트. 기준 코드 CommentItem.tsx 현재 배치를 좌측, 제안 A안을 우측에 나란히. 레퍼런스(유튜브·네이버·인스타)는 배치 관행만 참고하고, 색·폰트는 장터 팔레트(navy/gold/orange)를 유지.

레퍼런스 배치 관행
· 유튜브: 좋아요/싫어요 + 답글을 본문 하단 액션바에 한 줄. 수정/삭제·신고는 우상단 ⋮ 오버플로 메뉴로 접음. 시간은 닉 옆.
· 네이버: 공감/비공감 + 답글을 액션바에, 수정/삭제는 작은 텍스트 링크(우측). 시간·수정여부는 닉 옆.
· 인스타: 반응(하트)은 우측, 답글·시간은 메타 라인.
채택(A안): 유튜브식 ⋮ kebab로 수정/삭제 접기(헤더 정돈, 특히 모바일) + 공감·비공감·답글을 액션바 한 줄 좌측 그룹. 공감 활성=오렌지 · 비공감 활성=회색(팔레트 불변).
