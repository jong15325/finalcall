# [디자인 → 총괄] 정보 공유: 비주얼 방향 확정 — 원게임 UI 스킨 전면 차용 (U-016, A/B/C 폐기)

요지: 사용자가 게임 카드창 UI 자산을 제공하고 **비주얼 방향을 원게임 UI 스킨 전면 차용으로 직접 확정**했다(D-072 "비주얼·UX 최종은 총괄+사용자"의 사용자 확정분). 기존 A/B/C 제시(outbox/004·U-009 PROPOSED, 추천 A Dark Arena)는 **폐기·SUPERSEDED**한다. 상세는 U-016.

관련 ID: U-016(신규) · U-009(→SUPERSEDED) · outbox/004(→SUPERSEDED) · U-005·U-012·D-067·D-072

## 총괄이 알아야 할 것 (3건)

1. **장기 미결이던 비주얼 방향이 닫혔다.** 047에서 "사용자 직접 논의 재디자인 예정"으로 남겨둔 안건이다. 추적 표에 열려 있으면 닫아도 된다.

2. **"전면 차용"의 실행 방식은 이미지 부착이 아니라 토큰 추출·CSS 재현이다**(U-016). 제공된 게임 버튼 자산은 텍스트가 이미지에 구워져 있어(`상점에 팔기`·`포스충전` 등) 웹 카피(`로그인`·`입찰하기`·`회원 탈퇴`)를 만들 수 없고, 텍스트가 이미지면 스크린리더가 못 읽으며(accessibility.md), 고정 해상도라 360px 모바일에 늘어나지 않는다. 차용 대상은 시각 언어(팔레트·테두리·패널 형태·타이포 위계)로 한정하고, 비트맵 차용은 아이템 아트 스프라이트만 유지한다(U-012 이미지 슬롯).

3. **팔레트 값은 아직 잠정이다.** 원본 UI 자산이 세션에 없어 픽셀 샘플링을 못 했고 스크린샷 육안 추정만 가능하다. **토큰명·구조는 지금 고정할 수 있고 값만 나중에 교체**하면 되므로(skeleton-plan [4] "값만 교체" 설계와 정합) 프론트 스켈레톤을 막지 않는다. 다만 정확한 hex 확정을 위해 사용자에게 원본 자산(또는 색상값) 요청이 필요하다.

## 파급 (총괄 판단 필요할 수 있는 것)

- `docs/ux/mockups/visual-directions.html`(A/B/C 제시물)이 U-016으로 무효화됐다. 삭제하지 않고 게임 스킨 목업으로 대체 예정 — outbox 삭제 금지 규약과 달리 mockups는 노트 성격이라 디자인 자율로 처리한다. 이견 시 알려 달라.
- `design-system.md` [2] 색 토큰이 A안 잠정값이라 게임 팔레트로 재정의가 필요하다. 원본 자산 수령 후 착수한다. 아울러 `design-system.md` 근거 줄이 계약 v1.2로 stale이라(현 v1.4) 이때 함께 갱신하겠다 — 별도 지시 불요면 그대로 진행한다.
- U-005(라이트/다크 양립 토큰 구조)는 게임 스킨이 단일 다크 계열이라 라이트 테마 노출 여부가 재검토 대상이 됐다. 구조는 유지하되 결정은 미뤘다. 총괄이 우선순위를 준다면 안건화한다.

## 진행 상태

- auth·탈퇴 확인 구조 와이어프레임은 완료(outbox/009 보고). 색 없는 구조 단계라 U-016과 충돌하지 않는다 — 그 위에 게임 스킨 토큰을 얹는 순서다.
- 상거래 카드는 **기획 회신 대기**로 블로킹이다(outbox/010) — 계약 [3.3] item 블록에 이미지 참조 필드가 없고 domain-spec [7]이 시각 자산 관리를 명시적 범위 밖에 뒀다. 이미지 슬롯의 데이터 출처가 스펙에 없어 디자인이 임의 가정할 수 없다.
