# 작업 노트 — 주제 5 아이템 도메인 (ON-HOLD)

유형 4 작업 노트. 근거로 인용 금지(참고용). 확정 아님.
상태: ON-HOLD. 사용자가 아이템 구조 재검토 중(레퍼런스 조사, 메이플식 아닌 다른 게임 구조 전환 가능성 열림). 총괄 인덱스에 ON-HOLD 추적 등록됨. 확정 전까지 ERD 진입 불가.

## 미확정 오픈 이슈
- item_template 마스터 데이터 채우는 방식(게임데이터 임포트 / 운영 등록 / 판매자 제안+승인) 미정.
- 최종적으로 어떤 게임의 아이템 taxonomy를 채택할지 미정.

## 현재까지 도출된 분석 (재개 시 출발점)
메이플식 복잡 구조(대분류 장비/소비/기타 → 직업별 무기/방어구/악세, 인스턴스별 옵션 다양)를 전제하면 중앙 마스터 없이는 문제 발생:
- 검색·시세 집계 파편화 / 정합성(표기 흔들림) 붕괴 / 카테고리·직업 매핑 신뢰 불가 / 통계 불가 / 운영 정책 앵커 부재.

제안 모델(하이브리드):
- item_template(정의 마스터) + category(계층형) + 매물이 template 참조 + 인스턴스 옵션(JSON, 검색 대상 소수만 인덱스 승격) + 등록 시점 표시 필드 스냅샷(이력 보존).
- 아이템을 두 층으로 분리: "정의(무엇인가)"는 마스터가 표준화·검색·시세 보장, "인스턴스 다양성"은 JSON이 흡수, "이력"은 스냅샷이 보존.

## P-007 초안 이력 (void)
- 규약(D-009) 이전 초기에 임시 언급된 P-007 초안 = "아이템 정보를 판매 리스팅이 소유하는 스냅샷 단독(중앙 카탈로그 없음)".
- 자유입력 유니크 중고품 가정에는 맞으나, 정형 게임 아이템 taxonomy(메이플식)엔 부적합으로 판단 → 미채택.
- P-003~007은 정식 발번·인덱스 등록된 적 없음 → void(재사용 금지). 정식 신규 발번은 P-008부터. (총괄 보고: outbox/006)
