관련: 013 재개 지시, management/notes/item-reference-survival-project.md(총괄 조사노트, 미확정 참고),

## 방향 전환 (사용자 레퍼런스 검토 결과)
메이플식 복잡 구조 → 서바이벌 프로젝트형 단순 구조. 총괄 조사노트가 입력 자료.

## 서프형 구조 요지 (조사노트 요약, 미확정 참고)
- 장비 정체성 축: 종류(9) x 속성(4) x 등급(2) = 72 조합 + 마법/펫/아바타 → 수백 미만.
- 인스턴스 변이: 레벨(1~9) + 특수스킬1(종류,수치) + 특수스킬2(종류,확률/지속). 정형 2슬롯.
- 카테고리 얕음(대분류 → 종류 2단).

## 재분석 (메이플식 하이브리드 대비 단순화)
- item_template 마스터 성립이 자명(유한·소규모) → 시드로 채움, 판매자 제안 플로우 불필요.
- 인스턴스 속성이 정형 컬럼으로 종결 → JSON 옵션 + 인덱스 승격 계층 제거(최대 단순화 지점).
- 검색·필터(종류/속성/등급/레벨/특수스킬)·시세 집계((template,레벨,스킬조합))가 전부 정형 인덱스.
- "동일 템플릿 다른 가치"(특수스킬 조합)는 남아 검색 필터가 핵심 요구로 유지 → 학습 가치 보존.
- 강화/합성 행위는 범위 밖(레벨=인스턴스 현재 상태로만 취급).

## 오픈 이슈 회답
- 이슈1 item_template 채우기: 고정 시드 세트(운영/마이그레이션). 판매자 제안 없음.
- 이슈2 taxonomy: 서프형 2단 채택. 실존 명칭·데이터 미사용 → 가상 명칭·수치 시드(IP 주의).

## P-007 이력
- void 유지. "스냅샷 단독" 초안 미채택. 신 모델은 "template FK 참조 + 인스턴스 정형 컬럼 + 표시필드 스냅샷".

## 결과 (D-044~048)
- 모델 4건 확정: D-044(서프형 (b)) / D-045(관계) / D-046(강화·합성 범위 밖) / D-047(고정 시드). 주제 5 종결.
- D-048: 아이템 도메인 자율 결정 예외. 세부(컬럼·특수스킬 목록 등 two-way door 포함)도 총괄 안건화 → P 발번 안 함. ERD/spec 아이템 설계 착수 시 선택지+추천으로 총괄에 올림.
- D-044 조건: 특수스킬 조합 필터·시세 집계 단위(템플릿·레벨·스킬조합) = ERD 검색·인덱스 필수 케이스.
