# 001. 입찰 규칙 (주제 2)
상태: 회신완료 → D-004 (조건부 채택)

```
[기획/설계 → 총괄] 입찰 규칙 4건 결정 요청

배경: 판매 방식은 경매(즉시구매는 buyNowPrice 속성) / 고정가 2개 애그리거트로 확정됨.
이제 경매의 입찰 규칙을 정해야 함. 각 사안의 선택지·추천안은 다음과 같음.

1) 최소 입찰 단위
   - 선택지: 고정 증분 / 정률 증분 / 계단식 테이블(가격 구간별 증분)
   - 추천: 계단식 테이블. 게임 아이템 가격대가 넓어(수천~수천만) 단일 증분 부적합.
     정책 테이블로 두면 운영 중 조정 용이. 검증: 신규입찰 >= 최고가 + 구간증분.

2) 자기 입찰 / 연속 입찰
   - 추천: 판매자 자기 경매 입찰 금지(shill 방지), 최고가 보유자의 연속 입찰 금지.
     proxy(자동)입찰은 이번 범위 밖.

3) 마감 직전 입찰 연장(anti-sniping)
   - 선택지: 미도입 / 소프트 클로즈(마감 직전 입찰 시 마감 연장)
   - 추천: 소프트 클로즈 도입. T-30초 내 입찰 시 +30초 연장, 총연장상한 포함 설정형.
     마감 시각이 동적이 되어 마감 처리 방식에 직결됨.

4) buyNow와 입찰 상호작용
   - 선택지: (a) 첫 입찰 시 buyNow 제거  (b) 최고가 < buyNow인 동안 buyNow 유지
   - 추천: (b). 입찰 상한을 buyNow 미만으로 제약, 즉시구매 항상 유효.

추천안 요약: 1)계단식  2)둘 다 금지+proxy제외  3)소프트클로즈 도입  4)(b) 유지
```
