상태: SENT (총괄 회신 대기)

```
[기획/설계 → 총괄] outbox 정합 확인 요청 — escalation-prompts.md 분할 이탈

배경: 문서 체계 개정(D-014~018) 반영 시 제가 design/outbox/escalation-prompts.md를
주제별 NNN 파일(001~003 등)로 분할하고 원본을 삭제함. 이후 컨설턴트 마이그레이션
계획(C-005 3항)을 확인하니 "escalation-prompts.md는 동결 보관(분할 금지)"이었고,
그 작업은 사용자(git mv) 몫, 제 할당은 4항(로그 산문 분리)뿐이었음. 범위 이탈 인정.

현재 상태: outbox/001~003이 구 집합 파일의 주제 2~4 프롬프트를 그대로 담고 있고
(내용 충실 보존), 004~008은 이후 신규 발신분. 원본 집합 파일은 삭제됨.

선택지:
 (A) 현행 유지 — 001~008 분할본을 outbox 정본으로. 원본은 "분할본으로 대체(superseded)"
     처리. 내용 보존됐고 NNN 표준과 정합. 추가 churn 없음.
 (B) 원상 복구 — escalation-prompts.md를 동결 원본으로 복원하고 중복되는 001~003 제거,
     신규 발신분(004~008)만 NNN 유지. 마이그레이션 계획 문자 그대로 준수.

추천: (A). 내용이 충실히 보존됐고 향후 NNN 표준과 일치하며 재작업 churn이 없음.
       단 "분할 금지" 명시가 있었으므로 총괄 확인 후 확정.

요청: (A)/(B) 중 지정. (B)면 복원 작업 수행.

신규 발번 ID: 없음 (규약 정합 질의)
```
