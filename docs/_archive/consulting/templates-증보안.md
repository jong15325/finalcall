## 11. git 커밋 — docs (경량판)

```
docs(<역할>): <한글 제목 — 무엇을 왜>
```

본문은 다수 파일 변경·게이트·사고 복구 등 의미가 클 때만:

```
목적
- <1~2줄>
변경
- <파일/영역>: <무엇을>
관련: <D/C/P-xxx, G<N>, incident-NNN>
```

코드 커밋은 CLAUDE.md 6절 템플릿(수정 파일 M/A·검증 포함)을 그대로 쓴다.
docs 커밋은 파일 목록·검증 대신 결정 ID 연결이 추적 가치의 핵심이라 축약한다.
