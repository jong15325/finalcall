# 006. P-003~007 유령 ID 이력 보고 (D-011 각주용)
상태: 회신완료 → void 승인, decision-index 각주 반영. 신규 발번 P-008부터.

```
[기획/설계 → 총괄] P-003~007 유령 ID 이력 보고 (D-011 각주용)

배경: 규약(D-009) 이전, P-xxx 도입 초기에 작업 파일에서 임시로 P-003~006(주제 2 입찰 규칙
각 항목)과 P-007(주제 5 아이템-판매 관계 초안)을 잠깐 사용했으나, 정식 발번·인덱스
등록된 적이 없음. 이후 주제 2는 D-004로 확정되어 참조만 유지, P-007 초안(스냅샷 단독)은
아이템 구조 복잡성(메이플식) 검토로 미채택.

자율 결정: 소급 발번하지 않음. P-003~P-007은 void(재사용 금지) 처리. 정식 신규 발번은 P-008부터.
이유: 인덱스에 등재된 적 없는 번호를 소급 발번하면 이력이 오히려 왜곡되고, 재사용 금지
규약과도 상충. 티켓 시스템에서 결번(gap)은 무해하므로 gap으로 남기는 편이 안전.

요청: decision-index 각주에 "P-003~007 void(미발번·재사용 금지)" 1줄 반영.

신규 발번 ID: 없음 (void 이력 보고, 정식 발번은 차기 P-008 예정)
```
