# 002. 경매 생명주기·상태 전이 (주제 3)
상태: 회신완료 → D-005 (5건 채택 + 조건 3 + 범위절단 1)

```
[기획/설계 → 총괄] 경매 생명주기·상태 전이 5건 결정 요청

전제: 판매 방식은 Auction / FixedSale 2개 애그리거트. 아래 상태 머신을 제안함.

[Auction]
  SCHEDULED --(startAt)--> ACTIVE
  ACTIVE --(마감&유효입찰)--> SOLD
  ACTIVE --(즉시구매)-------> SOLD
  ACTIVE --(마감&입찰없음)--> UNSOLD(유찰)
  SCHEDULED|ACTIVE --(취소)--> CANCELLED
  SOLD/UNSOLD/CANCELLED = 종료

[FixedSale]
  ACTIVE --(구매)--> SOLD
  ACTIVE --(기한만료)--> EXPIRED
  ACTIVE --(취소)--> CANCELLED

결정 필요 5건:
3-1) 예약 시작(SCHEDULED) 지원 — 추천: 지원(지연 인프라 재사용, 한계비용 작음).
3-2) 종료 상태 표현 — 추천: status(SOLD/UNSOLD/CANCELLED) + resultType(BID/BUYNOW) 분리.
3-3) 취소 조건 — 추천: 판매자 취소는 "입찰 0건 & 진행 중"일 때만. 관리자 강제 취소 별도 권한.
3-4) 종료 이후(결제/배송) — 추천: 경매 FSM은 SOLD까지, 이후 Order 애그리거트 핸드오프.
3-5) 고정가 기한 — 추천: 선택적 endAt(있으면 EXPIRED, 없으면 무기한).

추천안 요약: 3-1)지원 3-2)status+resultType 3-3)무입찰시만 취소 3-4)SOLD까지+Order 3-5)선택적 기한
```
