# 004. 결정 로그 Jira식 티켓 규약 (크로스롤)
상태: 회신완료 → D-009, D-010, D-011

```
[기획/설계 → 총괄] 결정 로그를 Jira식 티켓 규약으로 격상 — 규약 확정 요청 (크로스롤)

배경: 현재 D/P/B/F/Q 접두어 번호는 있으나 세분화 기준·상태·참조 관계 미규정.
5역할 로그 전체 적용 규약이라 총괄 확정 후 collaboration-guide.md 반영 필요.

[지침안]
- ID: <PREFIX>-<3자리>, 접두어별 독립 증가, 불변, 재사용·재번호 금지.
- 1 항목 = 1 원자적 결정.
- 상태: PROPOSED / ACCEPTED / ON-HOLD / SUPERSEDED(대체 ID 명시).
- 필드: ID·제목·상태·소유역할·결정·이유·기각안·관련(참조 ID)·날짜.
- 참조 키워드: depends-on / relates-to / supersedes / escalated-as.
- 흐름: 역할이 PROPOSED 발번 → 총괄 확정 시 D-xxx 발번 → 원 역할은 escalated-as 참조. 중복 금지.

[결정 포인트]
1) 세분화: (a) 1결정=1번호(추천, 소급 재번호 없음) (b) 현행 유지
2) 상태 라벨 도입 — 추천: 도입
3) 마스터 인덱스 총괄 유지 — 추천: 유지

[덤] 총괄 D-로그 4번째 줄 경로 오류(domain-decisions.md → decision-log.md) 갱신 요청.
```
