## ⓑ 보류로 빠진 것 — 회수 (4건)

**컨설턴트 C-070 자백 형태 그대로다: "버린 게 아니라 미룬 것이고 미뤘다는 표시가 어디에도 없다."**

1. **홈 통합 피드 규칙** — **표시가 있으나 죽은 표시다.** `screen-spec [5]` 공백 1이 *"통합 노출 필요 시 결정 요청"*이라고 적혀 있다. **"필요 시"에 트리거가 없다.** 2026-07-14에 쓰고 오늘까지 아무도 안 열었다. ⓐ-7로 회수.
2. **플랫폼 수수료 정책 ON-HOLD** — `erd:278`에 `fee_amount` 자리만 있다. **sale_order가 마지막 도메인이라 제일 늦게 물린다** — 지금은 안 막지만 그래서 잊힌다. ⓐ-4로 회수.
3. **교환비율 ON-HOLD** — 추적표에 살아 있다(총괄 090 확인). **셋 중 유일하게 표시가 작동 중이다.**
4. **인증 세션 persist ON-HOLD** — `skeleton-plan [6]` #5. **표시는 있으나 자리가 틀렸다** — 보안(S) 사안인데 **기획 문서 안에만 있다.** 090에서 총괄이 *"교환비율 해소 시 동반 처리"*로 묶었는데, **둘은 무관하다**(하나는 돈, 하나는 XSS 노출면). 묶인 채로 두면 교환비율이 안 풀리는 한 persist도 안 풀린다.

**넷 중 셋이 같은 형태다: 표시는 했는데 트리거가 없다.** `templates [15]` 작업 리스트가 이걸 겨냥한 도구이나, **[15]는 요청 시점 산출이라 아무도 안 물으면 역시 조용하다**(컨설턴트 005가 자진 명시한 구멍 2번).

### ⓒ-2. 아이템 시드 — 원게임 실물 데이터

- **선택지**: (a) **사용자가 원게임 실물(명칭·수치·스킬 목록)을 선확보한 뒤 착수** / (b) 기획이 가상 시드 초안을 먼저 쓰고 실물이 오면 교체
- **추천: (a) 선확보.** D-067로 원게임 명칭·수치·코드 **전면 사용이 허용됐다** — 즉 실물이 정답이고 가상 시드는 **버려질 것을 쓰는 일**이다. D-062 안건2가 (b)를 채택했으나 **그건 D-067 이전 결정이다.** item은 백엔드 순서상 3번째라 아직 시간이 있다.
- **사용자에게 실제로 필요한 것**: 원게임 아이템 목록을 **어디서 어떤 형태로** 뽑을 수 있는지 1줄.

### ⓒ-3. 인증 세션 persist

- **선택지**: (a) **메모리 세션 유지**(현행 — 새로고침 시 재로그인) / (b) refresh 토큰을 브라우저 저장소에 persist
- **추천: (a) 유지하되, 보안(S) 검토를 wallet 착수 전에 건다.** (b)는 XSS 노출면을 만드는데 **이건 자금 시스템이다.** 다만 (a)에 실비용이 있다 — `/me/wallet/charge/confirm`이 외부 PG 리다이렉트 복귀 경로라 **하드 리로드로 세션이 날아가면 결제 승인 직후 사용자가 튕긴다.** 그래서 "(a)로 확정"이 아니라 "(a)로 두고 보안이 판정"이다.
