# [기획/설계 → 총괄] 결정 요청: domain-spec 아이템 소절 목차·서술 방향 (D-048 예외)

배경: domain-spec 초안 착수. 아이템 도메인은 D-048 자율 예외라 소절 목차·서술 깊이를
착수 시점에 안건으로 올림. 아이템 외 섹션은 병렬로 초안 작성 중. 근거 D-044~047.

안건 1. 아이템 소절 서술 깊이 (domain-spec vs ERD 경계)
- 선택지: (a) domain-spec은 개념·규칙만 — 템플릿/인스턴스 구분, 2단 카테고리, 매물-템플릿 관계,
              시드 정책, 범위(강화·합성 제외), 검색·시세 축. 구체 taxonomy 멤버(종류·속성·등급 실제 값)·
              특수스킬 목록·가상 명칭은 ERD(G2)에서 확정.
          (b) domain-spec에 구체 taxonomy·특수스킬 목록·가상 명칭까지 명시.
- 추천: (a). domain-spec은 개념·규칙 계층, 구체 스키마 값은 ERD가 정본(D-036). 단 D-048로 어느 쪽이든 확정 필요.

안건 2. 가상 명칭·수치 시드 초안 주체
- 선택지: (a) 기획이 완전 가상 명칭·수치 초안 제시 → 총괄·사용자 확정  (b) 총괄·사용자 주도 설계
- 추천: (a). 기획 초안 후 확정. IP 회피 위해 실존 게임 명칭·데이터 미사용.

안건 3. 아이템 소절 목차 승인
- 제안 목차: 1) 개념(item_template 정의 vs 인스턴스) 2) 카테고리 계층(대분류→종류 + 속성/등급 축)
  3) 인스턴스 속성(레벨 + 특수스킬 2슬롯) 4) 매물-템플릿 관계·표시필드 스냅샷 5) 시드 정책(고정 시드)
  6) 범위(강화·합성 제외, 레벨=상태값) 7) 검색·시세 축(특수스킬 조합 필터)
- 이 목차로 확정 요청.
