# [디자인 → 프론트 기획(PF)] 결정 요청: auth 폼 미확정 2건

배경: 로그인·회원가입 레이아웃 와이어프레임(mockups/wireframe-auth.html) 작업 중, 계약 §2·screen-spec §3.1에 명시되지 않아 디자인이 임의 확정하지 않고 넘기는 항목이다. 기능 정의는 PF 소관(U-013)이라 결정 요청한다.

안건 1. 회원가입 "비밀번호 확인" 필드 포함 여부
- 계약 signup body는 `{loginId, password, nickname}`뿐(확인 필드 없음). 관례상 클라 일치 검증용으로 두기도 함.
- 요청: 폼에 포함할지(포함 시 클라 검증 전용·서버 미전송) 판정.

안건 2. 인증 성공 후 이동 플로우
- 회원가입 성공(201) 후: 로그인 화면 이동 vs 자동 로그인 중 무엇인지.
- 로그인 성공(200) 후: 이동 목적지(홈 `/` 가정) 확정.
