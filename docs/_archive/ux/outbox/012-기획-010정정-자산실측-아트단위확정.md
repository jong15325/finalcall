## 정정 2 — 레벨 배지는 오버레이가 아니라 아트에 구워져 있다 (신규 발견)

- `level9/l/fire/sword.png`와 `level1/l/fire/sword.png`를 직접 열어 확인했다. **"Level 9"·"Level 1" 텍스트가 PNG 픽셀에 그려져 있다.** 별도 배지 레이어가 아니다.
- 영향: 010에서 내가 쓴 "레벨·골드포스·스킬은 계약 데이터로 아트 위에 오버레이"는 **레벨에 관해 틀렸다.** 웹이 계약 `level`로 배지를 그리면 아트의 구운 배지와 **중복 표기**된다.
- 디자인 판정(확인 요청): 카드의 레벨 **시각 표기는 아트에 위임**하고, 계약 `level`은 필터·정렬·시세 키·접근성 대체텍스트로만 쓴다. 웹이 레벨 배지를 따로 그리지 않는다.
- 단 이건 트레이드오프가 있다 — 아트의 구운 배지는 원게임 폰트·언어라 확대 시 흐려지고 스크린리더가 못 읽는다. 그래서 대체텍스트(`아이템명·속성·레벨`, accessibility.md)에는 `level`을 반드시 넣는다.

## 디자인이 자체 처리하는 것 (회신 불요, 통지)

- 자산이 50×93 / 26×28 **픽셀 아트**라 웹 확대 시 보간 처리가 필요하다. `image-rendering: pixelated`(nearest-neighbor)로 원본 도트를 보존한다 — 부드러운 보간은 도트를 뭉갠다. 상거래 카드의 이미지 슬롯 크기는 원본의 정수배(2x·3x)로 잡아 도트 왜곡을 막는다. 표현 소관(U-012)이라 자율 결정한다.
- `s`(26×28) = 목록 카드, `l`(50×93) = 상세 대응으로 설계한다. 다만 50×93은 상세 화면 주인공으로 쓰기엔 매우 작아 3x(150×279) 확대를 전제한다.
