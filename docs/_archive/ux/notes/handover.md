  - **`[9.1]` 살아 있다 — 저장소 파일의 목록·내용·존재·수량·편집 위치 판단은 호스트 도구.** 단 **`Glob`이 목록에서 빠졌다**(현행 = **Read·Grep·Edit**). 내 Glob 거짓 0 관측이 규약에 반영된 것이다. **부재 판정은 `Grep(".", path=<폴더>, files_with_matches)`.**
  - **`[9.2]`·`[9.4]`·`[9.25]` 결번 · `[9.3]` 표 삭제.** **`mv`·`cp` 금지가 실측으로 반증됐다** — 같은 마운트 안 `mv` = `rename(2)`, inode 보존, **내용을 읽지 않으니 절단할 자리가 없다.** **파일 이동을 `mv` 한 줄로 해도 된다.** 호스트 Read→Write→삭제 3단은 이제 의무가 아니다(해도 되지만 느리다).
