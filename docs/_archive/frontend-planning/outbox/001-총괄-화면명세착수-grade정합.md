- 선택지: (a) 총괄이 v1.2 지식 동기화 겸 전 역할 전파(등급 제거·§3.3 스키마) + 디자인 U-004 SUPERSEDE·프론트 note 갱신 지시 / (b) PF가 디자인·프론트에 정보 공유 직접 발신(총괄 사후 통지)
- 추천: (a) — 등급 제거는 도메인 연계라 '기획 경유'(D-072, PF) 대상이나 타 역할 소유 문서 갱신·SUPERSEDE는 경계 침범(에스컬레이션 2)이라 총괄 시퀀싱(D-074)이 적절. v1.2 확정 후 지식 동기화가 누락된 것으로 보여 일괄 전파가 깔끔.
