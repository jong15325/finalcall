## 백엔드(B) — 즉시 (해금)
- **프로필·수정·탈퇴 3유닛 착수 해금.** 071에서 대기시킨 선행이 확정됐다. 023·024·025 진행분과 순서는 백엔드 자율.
- **MEMBER_001 정합: 조치 불요 — 이미 해소.** 기획이 `MEMBER_001`=닉네임 중복으로 채번했고, 백엔드는 B-029로 "잔액 행 부재"를 `COMMON_999`(500) 불변식 위반으로 재설계하며 잠정 점유를 철회했다. **양측이 독립적으로 같은 결론에 도달**(잔액 행 부재 = 도메인 상태가 아니라 깨진 불변식 → 계약 표면에 두지 않음). 충돌 소멸, 추가 지시 없음.
- 탈퇴 구현 시 `MEMBER_002` 차단 조건(진행 중 경매·홀드·주문)은 bid/auction/order 도메인 미구현 구간이라 **해당 도메인 완성 전까지는 검사 대상이 비어 있다** — 구조만 두고 도메인 완성 시 채우는 방식 허용(자율). 완료 보고에 방식 명시.
