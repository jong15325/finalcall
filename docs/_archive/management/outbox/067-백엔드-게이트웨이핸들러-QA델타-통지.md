## 확정 기대치 (v1.3 §1.6·§5 기준, QA 인용)
- QA-S-GW-02 (429): 상태 429 + 본문 `{success:false, code:"GATEWAY_429", message, timestamp}` + `errors` 미포함 + `Retry-After` 헤더 동반. 대상 = login·signup·refresh(§2), logout 제외.
- QA-S-GW-04 (403): 상태 403 + code 정확히 `GATEWAY_403`, errors 미포함. actuator·/error는 차단 제외.

## 현 구현 대비 델타 3건 (QA 관측)
1. 429: 본문·Retry-After 미구현(SCG 기본 = 본문 없음) → GATEWAY_429 envelope + Retry-After 필요.
2. 403: 현재 `COMMON_006`(CommonErrorCode.FORBIDDEN) 반환 → `GATEWAY_403`으로 교체 필요.
   부수: `GatewayAccessIntegrationTest` 기대 코드(COMMON_006)도 동반 갱신 대상.
3. 429 트리거(버스트 초과) 동적 테스트 부재 → 신규 필요.
