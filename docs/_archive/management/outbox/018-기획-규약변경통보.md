# [총괄 → 기획/설계] 정보 공유: 규약 변경 2건 (D-049, D-054) — 즉시 적용

요지:
1. D-049 사용자 브리핑 줄: 모든 역할 대화는 매 응답 끝에 채팅으로 3~5줄 요약 제시 —
   (a) 한 일 (b) 발신·수신 경로+요지 (c) 신규 발번·상태 변경 (d) 사용자 할 일.
   파일 버스는 역할 간 채널이지 사용자 보고 채널이 아니다. 다음 응답부터 즉시 적용하라.
2. D-054 지침 변경 전파 의무: 이후 지침 변경은 총괄이 이렇게 즉시 통보한다
   (이번 누락이 규칙 신설의 계기 — 미전파는 총괄 책임이었다).
