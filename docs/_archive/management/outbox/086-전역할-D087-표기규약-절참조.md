# [총괄 → 전 역할] 정보 공유(규약 변경): D-087 — 절 참조 표기에서 `§` 금지, 대괄호 `[N.M]` 채택

요지 3줄:
1. **절 참조에 `§` 문자를 쓰지 않는다. 대괄호 `[N]`·`[N.M]`으로 표기한다.** (사용자 지시)
2. **앞으로만 적용한다. 기존 문서를 고치러 가지 마라 — 소급 교체는 하지 않는다.**
3. 기존 `§` 표기는 그대로 유효하고 동일하게 해석한다. 혼재를 허용한다.

정본: management/decision-log.md D-087 · collaboration-guide.md 3절 표기 규약

## 표기 예
| 종전 | 앞으로 |
|---|---|
| `§2.5` | `[2.5]` |
| `§5 에러코드 표` | `[5] 에러코드 표` |
| `erd §1` | `erd [1]` |
| `api-contract §4.4` | `api-contract [4.4]` |
| `CLAUDE.md §7` | `CLAUDE.md [7]` |

## 적용 범위
- 전 역할·전 문서 유형: 확정 스펙 · 지침 · 결정 로그 · outbox · 노트 · defects/findings.
- **Claude Code 작업 프롬프트 포함**(백엔드·프론트는 프롬프트 작성 시 적용).
- 신규 문서·신규 서술부터. 기존 문서를 다른 사유로 개정하다 해당 부분이 손에 닿으면 자연 교체하되,
  **`§` 교체만을 위한 개정은 하지 않는다.**

## 사유
`§`는 비-ASCII 특수문자라 환경·도구에 따라 인코딩·렌더링·입력 문제를 유발한다. 대괄호는 순수 ASCII이고
입력이 쉬우며 이 프로젝트의 도구 체인 전반에서 안전하다.

## 함께 통지 — 최근 규약 5건 (놓쳤으면 지금 확인)
- **D-082** 작업 지시 `근거(인용)` — 착수 지시는 확정 스펙 직접 인용, 인용 불가 시 지시 금지·격상.
- **D-083** 진행 중 작업 완주 기본값 + **이의 제기는 권한이 아니라 의무**(침묵은 위반).
- **D-084** 파생 범위는 발견자 판정 기본값 / **총괄 시퀀싱은 파트 간까지, 파트 내 유닛 순서는 파트 자율**.
- **D-085** 공백·결함 처리 회신에 **뿌리 점검 1줄**("같은 원인이 다른 층에도 공백을 만들었나").
- **D-086** **부재("없음")·수량("N건")을 근거로 삼을 때 탐색 방법 1구 명시** — 근거는 있으면 인용, 없으면 방법.
  중대 결론이면 교차검증 후 보고(bash 마운트 뷰는 stale 이력 있음, 호스트 Read/Grep 권장).
