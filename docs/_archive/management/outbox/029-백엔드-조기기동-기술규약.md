# [총괄 → 백엔드] 작업 지시: 조기 기동 — 기술 규약 협의 (D-035)

배경: G1(domain-spec) 통과(2026-07-13). D-035에 따라 백엔드를 G1 직후 "기술 규약 협의 모드"로
조기 기동한다. ERD(G2)·api-contract(G3)이 참조할 기술 규칙을 먼저 합의해 재작업을 막는 것이
목적. 도메인 구현 단계 아님.

목표: ERD·계약이 기준으로 삼을 기술 규약 초안 합의.
완료 기준(협의 안건):
1. 테이블·컬럼 네이밍(단수/복수, snake_case, PK/FK 규칙, 시간 컬럼 Instant/UTC — CLAUDE.md 정합).
2. API URL 규칙(리소스 네이밍·버전·복수형), 페이징 방식(offset vs cursor), 정렬·필터 파라미터 규약.
3. 공통 응답/에러 포맷을 스켈레톤 ApiResponse·ErrorCode 기준으로 재확인(CLAUDE.md 섹션 5).
4. 위 결정은 백엔드 자율 범위지만 ERD/계약에 영향 → 확정분을 기획·총괄에 정보 공유(D-024)로 전달.
의존: domain-spec(ACCEPTED) — 있음.
하지 말 것: 도메인 코드 구현(스켈레톤 규약 준수), 계약·스펙 내용 변경(영향 시 6절 절차).
