# incident-001. 다중 세션 동시 편집으로 인한 문서 절단·소실 (2026-07-12, D-027 사고 회고)

사건: 같은 저장소 폴더를 쓰는 복수 대화 세션(총괄·기획·컨설턴트)의 파일 동기화가
충돌하여 문서가 바이트 중간에서 절단되는 사고가 반복 발생.
누적 6건 — 총괄 decision-log(D-009~018 소실), decision-index(꼬리 소실 2회),
collaboration-guide(UTF-8 절단), 컨설턴트 C-009 항목, C-011 항목.

영향: 결정 로그 정본 일부 유실(전부 복구됨 — 총괄 대화 컨텍스트·02 설계안 문서 기반).
git 미커밋 상태였다면 영구 유실이었음.

원인(시스템에서 멈춤): 세션별 파일 동기화 계층이 동시 편집 시 구버전으로 덮어쓰거나
쓰기 도중 절단함. 특정 대화의 실수가 아니라 인프라 특성.

재발 여부: 재발함(당일 6건). 마지막 건은 커밋 규칙 도입 이후라 커밋에서 즉시 복구 가능.

1. D 발번(총괄 검수 확정) 시점마다 총괄이 커밋 생성 — 복구 지점 상시 확보. [운영 중]
2. 한 시점에 한 대화만 문서 작업(순차 진행). 사용자가 병렬 지시를 피한다. [사용자 협조]
