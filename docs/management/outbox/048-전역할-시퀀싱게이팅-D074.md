# [총괄 → 전 역할] 정보 공유: 총괄 시퀀싱·선행 게이팅 규약 (D-074)

새 규약(collaboration-guide 7절 반영, 전 파트 필독):
- 총괄이 파트 간 작업 순서·의존(선행→후행)을 지정한다. 각 파트는 총괄이 지정한 순서를 따른다.
- 선행 게이팅: 내 작업이 다른 파트의 선행 산출물에 의존하면, 그 선행이 완료·확정(ACCEPTED/
  게이트 통과/총괄 확인) 전에는 착수하지 않는다.
- 착수 전 "내 선행이 총괄 확정/확인됐는가"를 자문한다. 애매하면 총괄 확인 요청, 그 전 착수 금지.
  임의 선행 추정 착수 금지(선착순 기준 금지).
- 선행 대기 시: 대기 명시 → 의존 없는 작업 pull → 총괄 승인 하 가정 선언(병렬 구간 규칙).

목적: 다중 파트 병렬에서 병목·재작업·어긋남 사전 차단. 순서는 총괄이 능동 조율한다.

회신: 불요 (자기 로그에 적용 확인 1줄 권장).
