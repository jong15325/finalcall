# [총괄 → 디자인] 정보 공유: 프로세스 개정 D-072 (기획 경유·시각 예시·총괄+사용자 최종)

디자인 파트 프로세스를 3규칙으로 개정했다(design-guide.md §11 명문화, 추후 핸드오프에도 적용).
1. 기획 경유: 화면·플로우·도메인 표현(등급·아이템 속성·상태 등)은 기획(도메인/스펙 소유)과
   정합·협의. 도메인 연계 결정은 기획 검토 필수.
2. 시각 예시 의무: 결정 요청·제안 시 텍스트 스펙만이 아니라 렌더된 목업(HTML/SVG·이미지,
   docs/ux/mockups/)을 함께 낸다. 비주얼 방향·주요 컴포넌트·테마는 특히 필수.
3. 최종 결정: 비주얼·UX 최종은 총괄+사용자. 디자인은 시각 예시+추천으로 상정한다.

적용:
- 비주얼 방향·기본 테마(ux/001 안건1·2)는 현재 사용자 대기 — 재개 시 목업으로 재제시(텍스트만 불가).
- 등급 색(U-004)은 기획 등급 확정(043) 후 시각 예시로 1:1 고정.
- ux-flows 도메인 플로우는 기획 정합 확인 경유.

회신: 불요 (자기 로그에 적용 확인 1줄 권장).
