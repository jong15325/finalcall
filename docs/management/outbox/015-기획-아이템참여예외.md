# [총괄 → 기획/설계] 정보 공유: 아이템 도메인 사용자 참여 필수 (D-048)

요지: 아이템 도메인(템플릿·인스턴스 속성·카테고리·특수스킬·시드)은 자율 결정에서
제외된다(D-006의 도메인 한정 예외). domain-spec 세부·ERD 아이템 테이블 설계는
착수 시점부터 안건(선택지+추천)으로 총괄에 올려라 — two-way door 세부(컬럼 구성,
특수스킬 목록 등)도 포함. 총괄이 사용자와 논의해 확정한다.
다른 도메인(경매·입찰·주문 등)은 기존 위임 규약 그대로다.
관련 ID: D-048, D-044~047
