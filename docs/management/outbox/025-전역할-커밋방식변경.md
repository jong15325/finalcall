# [총괄 → 전 역할] 정보 공유(긴급): docs 커밋 방식 변경 — 사용자 단일 실행 (D-061)

변경: 이제부터 docs 커밋의 git 실행은 사용자가 전담한다. 각 역할은 커밋을 직접 실행하지 말고,
작업 블록 종료 시 완료 보고 말미에 `docs(<역할>): 제목` 커밋 메시지 블록만 제안한다.
금지: 역할 대화의 git 대행, `git add -A`. 스테이징은 자기 폴더로 한정(`git add docs/<역할>/`).
