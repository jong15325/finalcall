## 도구 (실측)

- **★ 마운트 절단은 호스트 쓰기가 트리거다**(프론트 5/5 재현). **크기만 낡고 데이터는 신선하다** —
  커지면 절단, 줄면 NUL 패딩. **`sync`·`touch`·`sleep`·재열기 전부 무효. `cp`는 절단본을 복사한다.**
  **우회 = 마운트 밖(`/tmp`)에 호스트 Read 내용으로 재구성.**
- **`mv` 써도 된다**(C-075). 같은 마운트 안 `mv` = `rename(2)`, **inode 보존·내용 미독.**
  실측: `inode=7881299348057385` 전후 동일 · `df -T` 단일 fuse. **확인은 여전히 호스트 Read**(`[9.1]`).
- **Glob이 실재 디렉터리에 0건** — 5회 재현. **파일 목록은 `Grep(".", path=<폴더>, files_with_matches)`로.**
  **오늘도 또 glob 썼다가 0건 맞았다.**
- **bash `rm`이 기본 차단**(Operation not permitted). `mcp__cowork__allow_cowork_file_delete`로 1회 승인.
  **`mv`도 같은 관문에 걸리는지는 아무도 안 재봤다**(프론트 관측).
- 조항 **중복·결번**은 `^\*\*\[N\.\d+\]` Grep. **밀림은 `git show <해시>:<파일>` 대조로만.**
