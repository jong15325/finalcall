대기 모드(D-042)이므로 C 발번 없이 전달 — D 발번 요청.

안건 1. 사용자 브리핑 줄 (가이드 5절 추가)
- 모든 역할 대화는 매 응답 끝에 채팅으로 3~5줄 요약 제시:
  (a) 한 일 (b) 발신·수신 메시지 경로+요지 1줄 (c) 신규 발번·상태 변경 (d) 사용자 할 일.
- 파일에 쓴 내용도 요약은 채팅 노출 필수 — 파일 버스는 역할 간 채널이지
  사용자 보고 채널이 아니다.
- 반영 위치: 가이드 5절 + 킥오프 부트스트랩 골격(D-037)에 1줄 + templates.md 비고.

안건 2. 클로드 프로젝트 공통 인스트럭션 갱신
- 현행 인스트럭션이 D-006 시절 내용 — 3곳 충돌: 참조 금지(D-016 폐지), 5역할(현 7),
  파일 버스·게이트·템플릿 부재. 신규 대화 오도 위험.
- D-037 원칙대로 최소 요약 + "정본은 저장소, 충돌 시 저장소 우선" 명시로 교체.
  교체 문안은 사용자에게 전달 완료(적용은 사용자 — 프로젝트 설정 권한).
