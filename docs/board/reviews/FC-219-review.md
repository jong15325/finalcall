## 확인 내용

- 루트 댓글과 답글에서 비추천 버튼·카운트만 제거했으며 API·query의 `DISLIKE` 호환 처리는 유지됨.
- 모바일·PC 공통으로 작성자와 작성 시간이 한 행에 표시되고 `수정됨` 표시는 한 번만 유지됨.
- 접기 토글과 `expanded` 상태 제거 후 `replyCount > 0`이면 답글 스레드를 항상 렌더함.
- 답글 더 보기·오류 재시도·작성·멘션 코드 경로는 유지됨.
- 새 색·모션·토큰 또는 반응형 안티패턴 회귀 없음.

## Minor

1. 신규 테스트가 LIKE 요청 payload, 답글 재시도·더 보기·작성·멘션을 직접 실행하지 않아 상호작용 회귀 방지 범위가 제한적임.
2. 여러 공감 버튼의 접근성 이름이 모두 `공감`으로 같아 스크린리더에서 대상·카운트 구분이 어려운 기존 패턴이 남아 있음.

두 항목 모두 이번 요청 기능을 차단하지 않는 비차단 후속 개선으로 판정한다.
