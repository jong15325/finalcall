## 목표
디자인 게이트 승인 목업(`docs/ux/mockups/market-quickbuy-cardinfo.html`)대로, 아이템 마켓 목록에서 아이템 클릭/구매버튼 → **카드정보 스타일 구매 모달**로 **바로 구매**하게 실 React 구현한다. 상세페이지 네비게이션을 이 모달로 대체.

## 확정 스펙 (디자인 게이트 승인 2026-07-28)
- **상호작용**: 모달 팝업. 마켓 카드(`ShopCard`) 영역 클릭 또는 카드 위 구매 버튼 → 모달 오픈. `MarketPage`에서 바로 열림(상세페이지 이동 없음).
- **디자인**: 하이브리드 톤 — 모달 내부는 게임 다크블루 카드정보(카드썸네일·속성표·특수스킬·하단 판매가+구매CTA) 충실 차용, **최종 CTA "바로 구매"만 브랜드 오렌지**, 그리드/헤더는 앱 브랜드 톤 유지.
- **★ 랭크 뱃지(S/A/B/C) 제거** — 계약에 없는 연출이었음. 렌더하지 않는다.
- **★ 탭 제거 → 특수스킬만** — 기본특징/능력수치/합성조건 탭 삭제. 특수스킬 섹션을 탭 없이 직접 노출.
- **상세페이지 대체**: 클릭 시 모달. `/market/:id`(`MarketDetailPage`)는 딥링크 seam으로 잔존 가능(제거는 범위 밖).
- **반응형 별도**([[responsive-separate-design]]): 웹=중앙 모달, 모바일=하단 시트 + sticky 하단 구매바.

## DoD
- 카드정보 구매 모달 컴포넌트 구현. 속성표(명칭·타입·종류·레벨·속성·남은 골드 포스)·특수스킬 목록(skill1/2·%)을 **실 리스팅 데이터**(`ShopSummary`/`AuctionItemBlock` 필드)로 채움. 랭크 뱃지·탭 없음.
- 구매: `usePurchaseShop`(`POST /shops/{id}/purchase`) 연동. 성공→SOLD 반영·무효화, 실패 SHOP_004(이미판매)·SHOP_005(잔액부족)·SHOP_006(자기구매) 표면화. 금액/판정은 서버 기준.
- **상태 분기 재사용**(`ShopBuyPanel`/`ShopPurchaseDialog` 로직): 비로그인→로그인 유도(returnUrl)·판매종료→비활성·자기상품→비활성(DOM disabled·WCAG). 모달 배선(포커스 트랩·스크롤 잠금·Esc·backdrop·role=dialog)은 `ShopPurchaseDialog`에서 이식.
- `MarketPage` 카드 클릭 인터랙션을 네비게이션→모달로 교체. 웹/모바일 각각 확인.
- 프론트 typecheck·lint·관련 vitest 그린. 커밋 금지(사용자 승인 대기).
