## 목표
사용자 목업(장터, Vuexy Bootstrap5) 핸드오프를 **기존 api-contract(정본) 기준으로 재조정**해

## 게이트1 결정 (2026-07-21 사용자 승인)
1. **범위 = 백엔드 준비된 화면만 실연동**(동결 유지). 미구현(마켓·충전·커뮤니티 CRUD·알림·OAuth·
   이메일인증·슬롯확장)은 "준비 중" 자리로만.
2. **계약 충돌 = 기존 api-contract가 정본.** 목업 추가개념(등급·확장 element·프레임 다종·스킬 이름·
   입찰 version)은 데이터 뒷받침 시만 렌더, 없으면 standard 폴백.
