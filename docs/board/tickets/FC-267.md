## 목표

AppShell의 viewport 높이 배분, sticky footer, 짧은 페이지 compact footer, mobile safe-area 책임을 구현 전 계약으로 고정한다.

## DoD

- `100dvh` AppShell과 `main 1fr`, 정상 문서 흐름 footer의 책임이 명시된다.
- 전역 content plane `min-h-full` 제거와 route별 viewport 최소 높이 금지가 명시된다.
- 404·오류·빈 상태·완료 화면의 의미 기반 compact footer 계약이 명시된다.
- MobileBottomNav safe-area와 CompareBar 하단 여유가 한 번만 예약되도록 소유권이 명시된다.
- 영향 이력과 비영향 범위, 사용자 승인에 따른 게이트2 DECIDED 근거가 기록된다.

## 근거인용

- 사용자 승인안(2026-08-12): `100dvh`, `main 1fr`, plane `min-h-full` 제거, 짧은 페이지 compact footer,
  mobile bottom nav safe-area 중복 제거.
