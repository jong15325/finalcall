## 목표
- 교환 요청 `cashAmount`에 상한이 없어, `cashAmount × rate`가 long 절대금액을 초과하면 `Math.multiplyExact`가
  `ArithmeticException`을 던져 **500**으로 샌다. 부수효과(차감·지급) 전에 발생해 잔액 정합은 안전하나(FC-010
  minor 1), 위생상 입력 검증(400) 또는 도메인 오류(422)로 정상화한다.

## DoD
- `ExchangeRequest.cashAmount`에 합리적 상한(`@Max`) 부여 → 초과 시 400 `errors[]`(검증 실패). 또는 오버플로를
  도메인 규칙 위반으로 매핑(422). 계약 §4.4 EXC 코드 체계와 정합하는 쪽으로 backend-impl 판단.
- 회귀 없음(기존 교환/멱등/동시성 테스트 그린) + 상한 초과 케이스 테스트 1건. reviewer 확인.
