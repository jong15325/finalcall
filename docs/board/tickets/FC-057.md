## 확정된 방향 (사용자 판정 2026-07-19)
> **레이아웃은 우리가 짜고, 템플릿 컴포넌트 37종만 정본으로 쓴다.**

- **데스크톱**: 상단 브랜드 + 계정/잔액 (1행) · **2행 내비** ·
  목록은 **좌측 필터 레일**(FC-059 소관) · 상세는 **하단 고정 입찰 바**(FC-059 소관)

  필터는 **바텀시트**(레일을 접는 게 아니라 **다른 컴포넌트로 교체** — FC-059 소관)

이 티켓은 **셸까지**다. 필터 레일·입찰 바는 화면 티켓이 얹는다.

## ★ 반드시 해소할 것 — 템플릿의 전제가 우리와 반대다
`Layouts.tsx`가 **`authenticated`로 셸을 가른다** → **비로그인은 헤더도 내비도 없는 화면**을 본다.
"로그인 안 했으면 볼 게 없다"는 **관리자 전제**인데, 커머스는 **손님이 첫 화면부터 둘러봐야** 한다.
(라우트 이분법은 FC-055가 `sharedRoutes` 3버킷으로 이미 고쳤다. **셸 분기가 남았다.**)

## ★★ 검색을 만들지 마라 — 계약에 없다
레이아웃 B 도식에 검색 바가 있었으나 **계약 §3·§4.1 어디에도 `q`/keyword 파라미터가 없다**(FC-048 확인).
지금 만들면 **동작하지 않는 컨트롤**이 된다 — §5.2 "사유 없는 비활성 금지" 위반이다.
→ **자리는 레이아웃이 수용하되 컨트롤을 두지 마라.** 계약이 규정되면 재설계 없이 들어간다.
   필요하면 **게이트2 상신 대상**으로 보고하라.

### 접기가 아닌 지점 4가지
(a) 내비 위치가 **위↔아래**로 다르다 · (b) 활성 지시선이 **밑줄↔윗줄로 뒤집힌다**(하단
가장자리에서 밑줄은 먹힌다) · (c) 계정이 **드롭다운↔`MY` 탭**으로 다른 컴포넌트 ·

(d)가 이 원칙의 실제 사례다. 같은 데이터를 접은 게 아니라 **다른 질문에 답한다.**

### 내비 목적지 — 백엔드 있는 4곳만
컨트롤러를 직접 확인해 `/`·`/auctions`·`/sell`·`/me/inventory`만 실었다.
뺀 것: `/shops`·`/market-prices`·`/me/orders`·`/me/wallet`(컨트롤러 없음.
`ExchangeController`는 교환만이라 wallet을 대체하지 못한다). **라우트는 살아 있어** 직접 주소는
자리표시자로 뜬다 — **내비에서 광고만 안 한다.**

**폭 변화 문제를 배치로 풀었다**: 데스크톱 2행은 `justify-between`이 아니라 **왼쪽 정렬 + 고정
간격**이라 항목이 늘어도 **기존 항목의 x좌표가 안 움직인다.** 모바일 탭바는 균등분할이라 그게
안 되므로 **5칸 고정**으로 못박고 추후 목적지는 `MY` 안쪽으로 들인다.

`sell`·`inventory`는 로그인 필수지만 **비로그인에게도 보인다** — 누르면 returnUrl 왕복으로
완결되지 빈 화면이 아니다. **감추면 손님은 팔 수 있다는 사실 자체를 모른다.**

### 템플릿 컴포넌트 / 자체 제작 3건
**썼다**: `Dropdown`·`Avatar`·`Button`·`Skeleton`·`LayoutBase`(blank)·`PageContainer`.
**만들었다**:

### 함께 처리한 3건
1. **returnUrl** — 복원 + 개선. `ProtectedRoute`가 **query·hash까지** 싣는다(종전엔 전역
   `location.pathname`만, 인코딩도 없었다). **오픈 리다이렉트 4종 차단.**
2. **404** — 전용 화면. 주소 유지 + 친 주소 되비춤 + 출구 2개. 셸 안에서 렌더.
3. **★ 244KB 청크 — FC-056 진단도 틀렸다(3차 진단, 2회 오진).**
   산출물에 아이콘 path 데이터가 **0건**이라 `react-icons/pi`가 아니었다(react-icons v5는 per-icon
   서브패스가 **아예 없어** "개별 임포트"라는 처방 자체가 불가능하다).
   식별자 지문(`MotionValue`·`projection`)으로 확인한 정체는 **framer-motion**.
   rollup importer 체인 실측: `AccountMenu → ui/Avatar(배럴) → AvatarGroup → ui/Tooltip → framer-motion`
   배럴 대신 `ui/Avatar/Avatar`를 직접 가리켜 **번들에서 완전 제거**(592→472KB, gzip 196→157KB).
   `vite.config.ts`에 `vendor-motion` 라벨을 남겼다 — 지금은 무동작이지만 Dialog·Drawer·toast를
   쓰는 순간 돌아오므로 **네 번째 오진을 막는 라벨**이다.
