## 목표
- **화면을 눈으로 검증할 수 있게 만든다.** 현재 시드는 `V9__item_seed.sql`뿐이고 **경매·입찰 데이터가 0건**이라, 프론트 목록이 텅 비고 상세 화면은 진입 경로조차 없다.
- FC-036/037이 만든 화면은 실제 브라우저에서 한 번도 렌더된 적이 없다(SSR 문자열 스모크만).

## DoD
- **로컬 전용 시드**. `local` 프로파일에서만 적용되게 하라 — Flyway 기본 위치에 그냥 두면 dev·prod에도 실린다. `spring.flyway.locations`를 프로파일별로 분리하거나(`classpath:db/migration,classpath:db/demo`) 동등한 방식을 쓰고, **선택 근거를 반환에 명시**하라.
- **경매 상태 전부를 화면에서 볼 수 있어야 한다**:
  - `SCHEDULED`(개시 전) · `ACTIVE`(진행) · `CANCELLED` · 마감 지난 것(status는 ACTIVE지만 `endAt` 경과 — 마감 워커가 없어 실제로 생기는 상태다)
  - **마감 임박 3종**: 여유(수 시간) · T-5분 이내(`warning` 색전이) · **T-30초 이내**(`danger`·소프트클로즈 윈도우). `Countdown` §5.9 색전이가 이 3구간을 보여준다.
  - 입찰 **있는 것/없는 것** 둘 다 — "입찰 없음 · 시작가 N" 표시와 "현재가 · 입찰 N회" 표시를 나란히 보려면 필수다.
  - 즉시구매가 **있는 것/없는 것** 둘 다.
- **입찰 데이터**: 여러 입찰자가 번갈아 밀어낸 이력(`ACTIVE` 1건 + `OUTBID` 다수) + 대응 `money_hold`(`HELD` 1 + `RELEASED` 다수). **불변식을 깨는 시드를 만들지 마라** — `game_money_held`와 원장 합계가 어긋나면 FC-034가 세운 불변식이 시드 때문에 거짓이 된다.
- **무한스크롤이 실제로 동작하는 양**: 최소 2페이지 이상(기본 page size 확인 후 결정).
- **아이템 다양성**: `element` **1(물)·2(불)만** 쓰라 — 3·4는 계약 v1.9가 미확정으로 남긴 코드다(FC-038 M-2). 미등록 코드 폴백("속성 N")도 보고 싶으면 **의도적으로 1건만** 넣고 그 의도를 주석에 남겨라.
- **typeCode 대역 주의**: 테스트가 81xx·82xx·83xx·84xx·852x·853x·86xx·87xx를 쓴다(FC-034 보고). 겹치지 않는 대역을 쓰라.
- 시드 사용자 계정의 **로그인 정보를 반환에 명시**하라(화면에서 로그인해봐야 한다).

## 금지
- **운영 데이터 경로를 건드리지 마라.** 이 시드가 prod에 실리면 안 된다.
- 화면을 잘 보이게 하려고 프로덕션 로직을 바꾸지 마라. 시드만 만든다.
