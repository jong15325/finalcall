## 목표
게시판 목록 페이지(`/boards/:slug`) 정상 상태에서 게시판 허브(`/boards`)로 돌아갈 경로가 없다(에러 상태에만 존재). 기존 상세 페이지의 "← 뒤로" 패턴과 일관되게 허브 복귀 링크(또는 브레드크럼)를 추가한다.

## 배경
- 상세 페이지(PostDetailPage)는 상단 "← {게시판명}"(→ boardPath(slug))·하단 "목록으로" 링크 보유(정상).
- 게시판 목록(BoardPostListPage)은 상단 세그먼트 탭으로 게시판만 전환·허브 복귀 링크는 `paths.boards` "게시판 목록으로"가 **board-not-found 에러 상태에만** 있음. 정상 상태 누락 = 사용자 신고.

## DoD
1. `BoardPostListPage.tsx` 정상 상태 상단에 허브(`paths.boards`) 복귀 링크 또는 브레드크럼(예: "← 게시판" 또는 "게시판 > {게시판명}") 추가. PostDetailPage "← 뒤로" 링크 스타일/패턴 재사용(TbChevronLeft·text-gray-500 hover:text-navy 등)로 일관.
2. 모바일/웹 모두 노출·터치 타깃 적정.
3. 기존 세그먼트 탭·글쓰기 버튼과 시각 충돌 없게.
4. typecheck·lint·build 통과.

## 근거
사용자 신고(2026-08-06): "각 게시판 상세페이지에서 목록으로 갈 수 있는 루트가 없음". 단순 UI 수정(디자인 게이트 불요).
