## 목표 (EPIC-ITEM-DELIVERY T5)
게임이 빈 폴을 돌리지 않도록 **커밋 후 best-effort 알림**을 발행한다. Redis는 알림 전용 — 실패해도 정확성 무영향(내구 정본=DB).

## DoD
1. **커밋 후 발행** — 정산 TX 커밋 완료 후(AFTER_COMMIT) `delivery:{recipient}` 신호 PUBLISH. TX 내 발행 금지(롤백 시 유령 신호 방지).
2. **실패 무해** — Redis 다운/발행 실패가 배송 정확성·정산에 전파되지 않음(로깅만). 정확성 백스톱 = 저빈도 안전망 폴 + 접속 시 claim(계약 명세).
3. AOP self-invocation 주의(외부 빈 경유). 발행 실패 주입 테스트.
