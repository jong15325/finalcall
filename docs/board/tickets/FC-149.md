## 목표
FC-148 확정 계약대로 `ShopSummary`에 **`sellerCompletedSales: long`**(판매자의 완료 판매 건수)를 채운다. 정의 = `COUNT(sale_order WHERE seller_id = shop.seller_id)`(경매+마켓 합산, `sale_order` 존재=완료). 계약 정본: shop-spec §11 · api-contract §3.3.

## DoD
- `ShopSummary` DTO에 `sellerCompletedSales`(long, non-null, ≥0, 필드 말미) 추가 — 형상 보존(필드 1개 추가만).
- 세 응답 조립에 채우기: `GET /shops`(목록)·`GET /shops/{id}`(상세)·`GET /me/shops`. 상세/MyShop은 `ShopSummary` 상속으로 자동.
- **성능(N+1 금지)**: 목록은 **페이지당 배치 IN 집계 1쿼리** `SELECT seller_id, COUNT(*) FROM sale_order WHERE seller_id IN (:ids) GROUP BY seller_id` 후 앱 매핑(미등장=0). 기존 `(seller_id)` 인덱스 커버. 행별 카운트 금지. 키셋 커서 쿼리 무개입.
- **집계 정합**: 경매 낙찰 + 마켓 판매 합산(sale_order 공통 원장, source_type 필터 없이 seller_id만). 취소·유찰·만료는 sale_order 행이 없어 자동 제외.
- **스키마·인덱스·에러코드 신규/변경 0**. Flyway 무변경.
- 테스트: 합산(두 채널)·취소/만료 제외·이력 없으면 0·목록 배치 집계. `./gradlew :backend:spotlessApply :backend:checkstyleMain :backend:test` 그린.
- 커밋 금지(사용자 승인 대기).
