## 목표 / DoD

네비게이션이 문서 흐름을 따르다가 콘텐츠 상단 경계와 맞닿는 순간 sticky로 고정되는 접점 고정형과 최신 contextual navigation 변형을 비교한다. 모든 안에서 navigation/content/footer의 가로 경계와 폭은 동일해야 한다.

## 시안

- 접점 고정형
- 도킹 전환형
- 컴팩트 도킹형
- 방향 반응형

## 파생 경위

사용자가 처음부터 떠 있는 sticky가 아니라 콘텐츠와 맞닿는 순간 유기적으로 고정되는 동작과 최신 흐름의 비교안을 요청해 FC-293에서 파생했다.

## 사용자 선택

2026-08-13 접점 고정형을 선택했다. 최초 진입부터 상단 여백 없이 viewport `top: 0`에 붙어 있고, 스크롤 시에도 콘텐츠와 접한 고정 상태를 유지한다. navigation/content/footer의 동일 가로 폭은 유지한다.

네비게이션과 콘텐츠 간격은 0으로 원복한다. 도킹 시 네비게이션 외곽에는 콘텐츠 영역과 동일한 라운드가 실제 배경 클리핑까지 적용되어야 한다.
