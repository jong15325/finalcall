## 목표 / DoD

네비게이션이 문서 흐름을 따르다가 콘텐츠 상단 경계와 맞닿는 순간 sticky로 고정되는 접점 고정형과 최신 contextual navigation 변형을 비교한다. 모든 안에서 navigation/content/footer의 가로 경계와 폭은 동일해야 한다.

## 시안

- 접점 고정형
- 도킹 전환형
- 컴팩트 도킹형
- 방향 반응형

## 파생 경위

사용자가 처음부터 떠 있는 sticky가 아니라 콘텐츠와 맞닿는 순간 유기적으로 고정되는 동작과 최신 흐름의 비교안을 요청해 FC-293에서 파생했다.

## 사용자 선택

2026-08-13 접점 고정형을 선택했다. 최초 진입부터 상단 여백 없이 viewport `top: 0`에 붙어 있고, 스크롤 시에도 콘텐츠와 접한 고정 상태를 유지한다. navigation/content/footer의 동일 가로 폭은 유지한다.

화면 상단과 네비게이션 사이에는 모바일 8px·데스크톱 12px 여백을 두되 네비게이션과 콘텐츠는 간격 0으로 붙인다. 상단 모서리는 라운드를 유지하고 뒤로 흰 콘텐츠가 비치지 않게 하며, 네비게이션·콘텐츠 접합부에는 틈이나 둥근 wedge가 없어야 한다.

최종 모서리 방향은 네비게이션 상하좌우 네 모서리를 모두 콘텐츠 radius 어휘로 둥글게 처리한다. 라운드 바깥은 app-canvas가 보이고 콘텐츠의 흰 surface가 스크롤 중 모서리로 비치지 않아야 한다.

별도 backing 색은 사용하지 않는다. 컴팩트 도킹형·방향 반응형과 동일한 외곽 구조와 네 모서리 라운드 표면을 사용하고, 콘텐츠는 overlay 없이 바로 다음 흐름에서 시작한다.

최초 flow 상태에는 모바일 8px·데스크톱 12px 상단 여백을 두고, 스크롤 임계점에 도달한 stuck 상태에서는 `top: 0`으로 전환해 viewport 상단에 붙인다.
