## 목표

짧은·긴 route의 footer 위치, scroll, mobile fixed navigation, 접근성 회귀를 최종 판정한다.

## DoD

- 404·오류·빈 상태·완료 화면에서 footer가 viewport 아래에 붙고 불필요한 세로 스크롤이 없다.
- 긴 목록·상세·폼에서 footer가 콘텐츠 뒤로 밀리며 body 단일 scroll이 유지된다.
- compact footer가 동일 landmark·핵심 링크를 유지하고 의미 기반 variant로만 전환된다.
- iOS/Android safe-area, MobileBottomNav, CompareBar가 겹치거나 하단 여유를 중복 생성하지 않는다.
- 320px·390px·desktop·200% 확대, loading 전환, modal/drawer/body scroll-lock과 전체 frontend 검증을 확인한다.
- critical/major/minor 판정과 `review_status` 근거를 리뷰 산출물에 기록한다.

## 파생 경위

FC-268 구현의 layout·scroll·접근성·모바일 safe-area 회귀를 확인하기 위해 파생됐다.
