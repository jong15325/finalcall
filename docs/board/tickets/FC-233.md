## 목표

두 상세 화면이 공유할 속성 배경 컴포넌트와 최적화 자산을 계약대로 만든다.

## DoD

- `toElementKey`를 재사용하고 1~4 외 코드는 중립 배경으로 처리한다.
- v3 원본 4종의 배포 파생본을 파일당 500KB 목표·800KB 상한으로 생성한다.
- 현재 속성 1장만 lazy load하며 다른 속성·목록 화면에서 선로드하지 않는다.
- CSS transform/opacity 중심 효과를 구현하고 Canvas는 물 속성 제한 효과에만 격리한다.
- reduced-motion·forced-colors·Page Visibility 정지·장식 레이어 비상호작용을 테스트한다.
- 로드/Canvas 실패가 자식 콘텐츠 렌더를 막지 않는다.

## 범위 밖

- 페이지 연결, API·백엔드·DB, AppShell 전역 및 공통 목록 배경.
