## 목표

경매 상세의 스킬 2 발동 확률을 마켓 카드정보 모달의 강조 문법으로 개선한다.

## DoD

- 스킬 2의 양수 확률만 `(N%)` 형식으로 별도 요소에 표시한다.
- 확률은 `orange-deep`, 800 굵기와 내부 줄바꿈 방지로 강조한다.
- 스킬명과 확률 사이 실제 공백과 접근 가능한 전체 텍스트를 유지한다.
- 스킬 1, 0 이하·비정상 확률, 무스킬 상태에는 확률을 표시하지 않는다.
- 스킬 2만 있는 아이템에서도 원본 슬롯과 확률을 유지한다.
- 전체 프론트 테스트, 타입 검사, 린트, 빌드를 통과한다.
