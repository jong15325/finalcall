## 목표
`mainCategory`·`subGroup`·`kind`·`element` 코드값이 계약·erd 어디에도 열거되지 않은 상태를 해소한다.
HANDOVER "EPIC-FE-AUCTION 후속 과제 2번(★ 코드 사전 부재 — EPIC-ITEM 정본화 필요)"의 처리 티켓이다.

## 발생 경위
FC-036(경매 목록·상세 프론트) 구현 중 `element` 코드값을 확정할 근거가 없어 계약 v1.9가 의도적으로
미확정으로 남겼다. 프론트는 "미등록 코드는 중립 표기(속성 N) 폴백 + 코드 집합 크기 하드코딩 금지"로
우회 중이라 당장 막히지는 않으나, **필터 UI 설계 시 `kind`의 축 해석이 `mainCategory`에 의존**하는
문제가 남아 있었다.

## 1차 근거 (2026-07-19 총괄 확보 — 원본 게임 DB `new_sp` 직접 조회)
`gameshop.itm_type`(4자리)이 `1 [mainCategory] [element] [kind]` 구조로 해독됐다.

- mainCategory: 1=WEAPONE(무기) · 2=ARM(방어구) · 3=MAGIC(마법)
- **element: 1=WATER · 2=FIRE · 3=EARTH · 4=WIND** ← 종전 "추정, 정본 근거 없음"이 해소됨
- kind는 **mainCategory 의존**:
  - WEAPONE: 1=AXE 2=WAND 3=SWORD 4=BOW
  - ARM: 1=SHIELD 2=PENDANT 3=ARMOR 4=BOOTS
  - MAGIC: 1=NOMAL 2=SPECIAL (**값이 2개뿐**)

행 예시: `1111 WEAPONE_WATER_AXE_CARD` / `1234 ARM_WIND_BOOTS_CARD` / `1342 MAGIC_WIND_SPECIAL_CARD`.
재확인: `docker exec finalcall-mysql mysql -usp -psp -N -e "SELECT DISTINCT itm_type, itm_name FROM gameshop ORDER BY itm_type;" new_sp`

## DoD
- 계약·erd·item-domain-spec의 현행 4축 정의를 읽고 **V9 시드 실제 값과 대조**한다.
- **`subGroup` 판별** — 원본 코드 체계에 대응물이 안 보인다. 우리 독자 축인지 판별하고, **불가하면 "판별 불가"로 명시**한다(지어내지 않는다).
- 원본 체계와 우리 축의 정렬 여부를 검증한다(element 1·2의 V9 일치 / kind의 mainCategory 의존이 계약에 반영됐는지 / 양쪽에만 있는 값).
- 코드 사전 변경안을 **`docs/spec/proposals/item-code-dictionary.md`에 제출**한다. `kind`는 mainCategory별 표를 분리한다(단일 표로 뭉치면 MAGIC이 2값뿐인 사실이 사라진다).
- **게이트2 상신용 결정 항목 목록**을 낸다 — 원본 코드 채택/재매핑/부분채택 트레이드오프 + 권고안.
- 영향 티켓 목록을 낸다.

## 게이트2 승인 (2026-07-19)
사용자가 D1~D5 전건을 architect v2 권고안대로 승인했다.

- **D1 = A 전면채택** — 원본 게임 코드 체계를 그대로 따른다.
- **D2 = d 자리 의미 교정** — `sub_group`은 잉여 축이 아니라 자리를 잘못 채운 것이었다.
  원본 `[상품군][main][element][kind]` ↔ 우리 `[main][subGroup][element][kind]`로 두 선두 자리가
  뒤바뀌어 있었다. 산식·컬럼·UK 무변경, 시드 8행만 바뀐다.
  **대가를 사용자가 수용**: `main_category`가 상수 1이 된다("정보량 0 축"이 `sub_group`에서 이동).
  → **필수 동반 조항**: `item_template` 스코프를 "상품군 1"로 계약에 명시.
- **D3 = (iii) 허용 + 계약 경고** — D2 확정에 따라 의존 대상 축 이름은 **`subGroup` 의존**으로 확정.
- **D4 = a 지금 확정** — element **1=물 · 2=불 · 3=흙 · 4=바람**(4경로 확증).
- **D5 = a** — 아트 키를 `(element, 물리종류)`로 정의.
