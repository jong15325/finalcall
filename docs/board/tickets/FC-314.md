## 목표
- 실제 경매 카드에서 남은 시간을 장식 배지가 아닌 신뢰 가능한 거래 데이터로 표시하는 후보를 비교한다.
- 상태 lozenge와 시간 데이터를 역할별로 분리하고 FinalCall 카드에 적합한 구조를 선정한다.

## DoD
- 미니 타임코드, 이미지 하단 경매 정보 레일, 상태·시간 분리의 3계열에서 총 12개 후보를 제공한다.
- 후보는 정보 구조와 배치가 실질적으로 달라야 하며 색상·폰트·radius만 바꾼 변형은 제외한다.
- 시간은 읽기 전용 데이터 컴포넌트로 표시하고 상태만 Vuexy 기반 공용 badge 포트를 사용한다.
- Atlassian lozenge/badge 역할 분리, Carbon compact read-only 지침, 실제 경매 카드의 timer-as-data 패턴을 근거로 남긴다.
- 금액·입찰 수·시간은 tabular 숫자를 사용하고 카드 링크의 pointer 동작을 방해하지 않는다.
- 390px과 1280px에서 카드·시간 표시의 overflow가 없으며 실제 브라우저 캡처로 확인한다.
- production build에 dev-only workbench가 포함되지 않는다.

## 검증
- 운영 카드에 5번 입찰·시간 레일을 artwork 다음 flow 영역으로 적용했다.
- 워크벤치 5번과 동일한 한 줄 `AuctionInfoRail > AuctionInfoGroup + AuctionTimeDisplay(bare)` 구조를 사용하며 위치만 artwork 직후 flow 영역이다.
- 별도 긴급 색상·추가 시계 아이콘·2행 변형 없이 skeleton도 동일한 37px 레일을 사용한다.
- 관련 테스트 21개, typecheck, 대상 lint를 통과했다.
- reviewer 재검토 결과 이번 변경의 critical/major/minor는 0건이다.
- 전체 `npm run build`는 범위 밖 dirty `WalletBalanceCandidate.tsx`·`WalletBalanceScenario.tsx`의 `border-y` workbench guard 위반으로 중단된다. 직접 Vite production build와 production residue 검사는 통과했다.
