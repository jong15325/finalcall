## 목표 (EPIC-COMMENT-V2 계약 선행 · contract-first)
기존 평면 댓글(FC-199/203 배포분)을 네이버 구조로 확장하는 계약·스키마를 정본화한다. 구현(FC-207~212) 전 계약 확정.

## DoD
1. **board-domain-spec.md 갱신(댓글 절)** — 대댓글 모델(1단계·parent_comment_id 활성·@멘션 대상·답글의 답글도 최상위 댓글에 귀속), comment_reaction 도메인, 정렬·BEST 규칙, 인가 불변식(반응 유저당 1회·본인 답글 수정삭제).
2. **erd.md 갱신** — comment_reaction 테이블(comment_id·user_id·type LIKE/DISLIKE·UK(comment_id,user_id))·comment 비정규화(like_count·dislike_count·reply_count)·인덱스. Flyway 버전 예약.
3. **api-contract.md §6 갱신** — 변경/신규:
   - 최상위 댓글 목록(+replyCount·likeCount·dislikeCount·myReaction) + **정렬 param(순공감순·최신순·과거순)**.
   - **답글 목록 API**(특정 댓글의 답글 지연 로딩, 네이버 "답글 N개").
   - **답글 작성**(parentCommentId·@멘션 대상).
   - **반응 토글 API**(공감/비공감 등록·전환·취소).
   - **BEST 댓글** 노출 규칙(별도 섹션 or 목록 플래그).
4. **게이트2 상신 3건**:
   - (a) 답글 1단계 저장 형상(모든 답글이 최상위 댓글에 붙음·@멘션 표현).
   - (b) 반응 스키마(comment_reaction·유저당 댓글당 1행·LIKE↔DISLIKE 전환·카운트 비정규화 동기화).
   - (c) 기존 댓글 API 형상 교체 파급 — FC-199/203이 방금 배포됨. 목록 응답 형상 변경(평면→최상위+replyCount)의 하위호환/마이그레이션 없이 교체 범위·영향 티켓 명시.
