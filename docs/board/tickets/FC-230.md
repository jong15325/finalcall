## 목표

경매 상세 카드정보의 사용자 노출 명칭과 값 형식을 아이템 마켓 카드정보 모달과 정확히 일치시킨다.

## DoD

- 제목을 `카드정보`와 `CARD INFO`로 표시한다.
- 정보 행을 `타입 → 명칭 → 채널제한 → 속성 → 남은 골드 포스` 순으로 표시한다.
- 공용 `channelLimitOf(level)`을 사용하고 모달에 없는 `종류`, `레벨` 행은 제거한다.
- 활성 골드포스 값은 `N일`, 만료·미적용은 `없음`으로 표시하며 중복 상단 골드포스 배지를 제거한다.
- 특수 스킬 제목, 숫자 슬롯, 확률 형식, 빈 상태와 접근성 라벨을 모달과 일치시킨다.
- 경매 상태 배지와 입찰 관련 영역은 유지한다.
- 전체 프론트 테스트, 타입 검사, 린트, 빌드를 통과한다.

## 범위 밖

- API·백엔드·아이템 마켓 모달 변경.
- 경매 상태·입찰 패널 변경.
