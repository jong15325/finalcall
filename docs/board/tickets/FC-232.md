## 목표

경매 상세 콘텐츠의 깊이와 집중도를 개선할 배경 효과 3안을 비교 가능한 HTML 목업으로 제시한다.

## DoD

- A 절제된 navy·gold 콘텐츠 halo, B 저대비 market grid, C 섹션 spotlight를 한 파일에서 비교한다.
- shipping 브랜드 팔레트와 Vuexy 라이트 카드 구조를 유지한다.
- 데스크톱·모바일 전환, 접근성, 정적 CSS 성능 제약을 반영한다.
- 실제 애플리케이션 코드는 사용자 디자인 승인 전 변경하지 않는다.
- 외부 사이트의 시각 디자인은 복제하지 않고, 전체 화면 배경과 독립 콘텐츠 셸이라는 레이아웃 방식만 FinalCall 전용 배경으로 검증한다.

## 디자인 게이트

- 목업 제시 후 적용안과 적용 범위(상세 경로 한정 또는 AppShell 전역)를 사용자에게 확인한다.
- 몰입형 배경 목업의 명암(원본/권장/집중)과 적용 범위를 사용자에게 확인한다.
