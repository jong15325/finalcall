## 목표

경매 상세의 아이템 정보란을 아이템 마켓 카드 정보 모달의 승인된 정보 구조와 표현으로 통일한다.

## DoD

- 기존 아트와 입찰 패널은 유지하고 아이템 정보 영역만 재구성한다.
- 카드 타입을 활성 골드포스 기준 `골드/블랙 - {대분류}`로 표시한다.
- 속성, 종류, 레벨과 골드포스 적용 여부·잔여일을 명시한다.
- 스킬 1·2의 원본 슬롯, 이름 폴백, 스킬 2 확률을 표시하며 무스킬 빈 상태를 제공한다.
- 기계 문자열 `specSnapshot`은 표시하지 않는다.
- 모바일에서는 입찰 패널 우선 순서와 아이템 정보의 자연스러운 줄바꿈을 유지한다.
- 공용화를 수행한다면 모달 chrome이 아닌 순수 정보 본문만 추출하고 마켓·인벤토리 회귀를 검증한다.
- 전체 프론트 테스트, 타입 검사, 린트, 빌드를 통과한다.

## 디자인 게이트

- 사용자가 아이템 마켓 카드 정보 모달을 디자인 정본으로 직접 지정해 방향 승인 완료.

## 범위 밖

- API·백엔드·입찰 패널·입찰 이력 변경.
- 새 색상 또는 새로운 모달 인터랙션 도입.
