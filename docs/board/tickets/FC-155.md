## DoD
- **`SocialLoginButton` 공용 컴포넌트** 신설(design-system §5.11 U-021 명세대로 — kakao `#FEE500`·naver `#03C75A` §2.8, 접근성·브랜드 규격 준수). 현재 SignupForm 인라인 하드코딩 버튼을 이 컴포넌트로 교체.
- **로그인·회원가입 두 화면** 모두에 카카오·네이버 버튼 배치. **로그인 화면 누락분 보강**(LoginForm에 현재 소셜 버튼 없음, 목업엔 있음 — 불일치 해소).
- 버튼 클릭 → provider authorize URL로 이동(client-id·redirect-uri·state 구성). `disabled`/"준비 중" 제거.
- 반응형·접근성(엄지 도달·포커스). `npm run build`·lint 그린. 커밋 금지.
- **키 요청**: 착수 시 client-id·redirect-uri(공개값) 필요 — 총괄이 사용자에게 요청.
