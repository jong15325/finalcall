## 목표

실시간 경매 목록 카드에서 아이템 마켓과 동일한 공용 표현을 사용해 스킬 1·2와 골드포스 남은 일을 명확히 보여준다.

## DoD

- `ItemSkillSummary`를 재사용해 스킬 1·2 이름, 스킬 2 확률, 코드 폴백, 무스킬 상태를 표시한다.
- 스킬 슬롯 번호는 원본 슬롯을 유지하며 스킬 1이 없어도 스킬 2를 스킬 1로 재번호하지 않는다.
- 골드포스 잔여일은 `ItemFrame`과 공용 계산 규칙을 재사용하고 중복 계산·표현을 만들지 않는다.
- 기존 Vuexy 목업의 카드 정보 밀도와 shipping 브랜드 팔레트를 유지한다.
- 320px·375px 모바일 및 데스크톱에서 긴 스킬명, 2개 스킬, 3자리 잔여일, 무스킬 카드의 높이·오버플로를 검증한다.
- 단위 테스트, 전체 프론트 테스트, 타입 검사, 린트, 빌드를 통과한다.

## 범위 밖

- 경매·아이템 API 및 백엔드 변경.
- 새로운 카드 인터랙션이나 스킬 뒤집기 버튼 추가.
- 관리자 기능.
