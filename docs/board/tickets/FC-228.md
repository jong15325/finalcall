## 목표

실시간 경매 카드의 제목을 아이템 마켓과 동일한 프레임·대분류 타입 표현으로 통일한다.

## DoD

- 시각 상품명과 `Lv.N` 행을 제거한다.
- 비활성·만료 골드포스는 `블랙 - {대분류}`, 활성 골드포스는 `골드 - {대분류}`로 표시한다.
- 대분류는 공용 `subGroupLabelOf`, 활성 여부는 공용 골드포스 판정을 재사용한다.
- `nameSnapshot`은 링크 접근성명, 아이템 프레임 이름, 비교 기능 식별에 유지한다.
- 카드·스켈레톤 최소 높이 256px와 스킬 표시를 회귀 검증한다.
- 전체 프론트 테스트, 타입 검사, 린트, 빌드를 통과한다.

## 범위 밖

- API·백엔드·카드 높이 변경.
- 아이템 마켓 카드의 표현 변경.
