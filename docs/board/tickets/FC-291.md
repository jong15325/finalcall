## 목표

브라이트 스틸과 맥락별 focus 토큰을 전역 registry와 기존 semantic consumer에 적용한다.

## DoD

- chrome `#32475A`, strong/raised `#273746`, selected `#32475A`를 기존 semantic alias에 적용한다.
- action `#3D5F7C`, hover `#2E485F`, ink `#FFFFFF`를 모든 일반 primary action에 적용한다.
- light surface/canvas focus는 `control-focus #C38000`, steel chrome focus는
  `control-focus-on-dark #C78300`을 소비한다. dark chrome 안의 밝은 overlay는 light focus로 복귀한다.
- success/danger/warning/info와 각 ink/soft, `action-soft`, route element token은 변경하지 않는다.
- 새 페이지별 override·병렬 palette·raw color를 만들지 않는다. `brand-navy*` 물리 식별자는 호환을 위해
  유지하되 새 consumer는 semantic token만 사용한다.
- UI guard가 계약의 action ink 4.5:1과 focus 여섯 조합 3:1을 계산하고, typecheck·lint·test·build가 통과한다.
