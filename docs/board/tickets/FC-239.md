## 목표

두 상세 route에서만 AppShell chrome이 속성별 몰입형 글래스 셸 토큰을 소비하는 안전한 기반을 만든다.

## DoD

- provider가 pathname을 검증하고 성공 응답에서 등록된 정적 element key만 소비한다.
- body/html 전역 상태·localStorage를 사용하지 않고 pathname 변경·unmount에서 초기화한다.
- Sidebar·TopNavbar·footer·CompareBar·MobileBottomNav에 시맨틱 반투명 chrome 토큰을 적용한다.
- 다른 route의 기존 class/token/시각 baseline과 요청·theme selector 0건을 테스트한다.
- dropdown·drawer·modal z-index, focus, sticky와 body scroll-lock을 깨는 stacking/overflow를 만들지 않는다.

## 범위 밖

- 파티클 엔진, 상세 카드/CTA 재디자인, API·백엔드·DB.

## 파생 경위

FC-238 이후 승인된 v2 AppShell 전체 chrome 테마 변경에서 파생됐다.
