## 목표
카드정보 구매 모달의 **전체 디자인 변형 3~4개**를 HTML 목업으로 나란히 제시해 사용자가 유지/변경을 고르게 한다([[options-need-html-mockup]]). 사용자 요청: "상단 레이아웃 변경 + 전체 디자인 수정해서 새 디자인 예시 몇 개 + 하단 판매자 정보가 뜬금없고 너무 작음."

## 유지 (구조·자산·아이 톤 방향)
- **레이아웃 구조 요소**는 유지: 헤더 + 카드 이미지 + 속성표 + 특수스킬 + 가격 + 구매 CTA.
- 카드 이미지 = 게임 자산, **배경 없이 딱 맞게**(현행대로, 다시 넣지 말 것).
- 속성 = 타입·명칭·채널제한·속성·남은 골드 포스. 특수스킬 목록 유지.
- 기본 aesthetic = **앱 라이트/클린 커머스 톤**(흰 표면·연회색 서브패널·헤어라인·네이비 포인트·오렌지 CTA). 게임 다크 네이비 패널로 회귀 금지. 변형은 이 톤 안에서 다양화(과감한 대안 1개 정도는 허용하되 "게임 패널 복귀"는 아님).
- 참조: 현행 `frontend/src/features/shop/components/ShopCardInfoDialog.{tsx,css}`가 시각 베이스. `docs/ux/mockups/market-quickbuy-cardinfo.html` 참고.

## 반드시 반영 (사용자 지적)
- **상단 레이아웃 변형**: 썸네일 배치/크기·속성 제시 방식을 변형마다 다르게(좌우 2열 / 상단 히어로 / 가로 히어로 / 컴팩트 그리드 등).
- **★ 판매자 정보 개선**: 현행은 하단에 "판매자 OOO"가 **뜬금없고 너무 작음**. 각 변형에서 판매자 정보를 **적절한 위치·읽히는 크기**로 정리(예: 가격 블록 옆 라벨/아바타·명확한 "판매자" 라벨). 뜬금없지 않게 맥락에 녹여라.

## DoD
- `docs/ux/mockups/card-info-design-variants.html` 생성. **완결된 카드정보 모달 디자인 3~4개**를 라벨(A/B/C/D)·각 변형 특징 1줄과 함께 한 파일에서 나란히 렌더(상단 배치·판매자 정보 처리·전반 톤이 서로 구분되게). 각 변형은 헤더~구매 CTA까지 완결 모달.
