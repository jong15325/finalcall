## DoD
- **Flyway V10**(`V10__auction.sql`): auction 테이블(seller FK·item_instance FK·startPrice·buyNowPrice?·startAt?·endAt·softCloseWindowSec·softCloseExtendSec·maxEndAt·base_end_at·extension_count·status·resultType·highest_bidder_id·highest_bid_amount). erd v0.9·auction-domain-spec 정합. status는 DB ENUM 5값.
- **엔티티**: `Auction`(+`AuctionStatus` 5값·`AuctionResultType`)·`AuctionErrorCode`(AUCTION_001~008, 001=403). 섹션 5 컨벤션. 소프트클로즈 config **저장만**(기본 30/30, base_end_at=end_at, extension_count=0).
- **등록 API** `POST /api/v1/auctions`(인증 필요): item INVENTORY→LISTED **조건부 CAS**로 이동(중복출품 AUCTION_002). SCHEDULED(startAt 있으면)/ACTIVE 생성. 검증: buyNowPrice>startPrice(AUCTION_003), 시간 파라미터 SEC-009(AUCTION_008), 소유·보유(AUCTION_001 403). 응답 201 `{auctionPublicId, status, endAt}`.

- **Repository**: findByIdOrThrow 패턴, QueryDSL 커스텀 골격.
- **테스트**: 등록 happy·검증 실패·중복출품 동시성(CAS 단일승자)·SCHEDULED/ACTIVE 분기. spotless·checkstyle 통과.
