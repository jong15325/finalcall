## 목표
평면 댓글을 1단계 대댓글로 확장. 답글 작성·답글 목록 API·최상위 replyCount·삭제 tombstone.

## DoD
1. **Comment 활성화**: parent_comment_id 활성(답글은 항상 루트 귀속·1단계), mentioned_nickname 스냅샷, reply_count 비정규화. Flyway V24(comment 컬럼 추가·인덱스 재편, erd v1.9 §4.5/§5).
2. **API**(api-contract v1.24 §6.3):
   - 최상위 목록 `GET /posts/{id}/comments?sort=` (기본 LATEST·enum LATEST|OLDEST|LIKES) — 루트만·replyCount 포함.
   - 답글 목록 `GET /posts/{id}/comments/{cid}/replies`(OLDEST 고정, offset).
   - 답글 작성 `POST /posts/{id}/comments/{cid}/replies`(parentCommentId·mentionedNickname 서버 파생).
3. **tombstone**: 활성 답글 보유 루트 삭제 시 마스킹 잔류(deleted:true·content/author null), 답글 없으면 완전 배제. reply_count·post.comment_count(루트+답글 총계) 동기화.
4. 인가·주체 SecurityContext·IDOR. spotless·checkstyle·통합테스트 그린.
