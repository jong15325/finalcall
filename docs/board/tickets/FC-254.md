## 목표

공통 outer gutter와 mobile white frame 변경의 접근성·layout·stacking·scroll 회귀를 최종 판정한다.

## DoD

- 모든 AppShell route에서 breakpoint별 gutter·radius·border·shadow·max width를 확인한다.
- 경매·아이템 상세 viewport 배경/particle이 gutter에 노출되고 content는 single plane 안에 있음을 확인한다.
- 중첩 page frame 없이 기존 card·CTA 계층과 loading·error·404 layout 안정성을 확인한다.
- 320px usable width·CTA/input, 200% 확대와 가로 scroll 0건을 확인한다.
- BidPanel/Compare sticky, dialog/dropdown/drawer/CompareBar stacking, focus와 body scroll-lock을 확인한다.
- plane의 overflow/transform/filter/z-index stacking context 0건과 AuthLayout 무변경을 확인한다.
- critical/major/minor 판정과 review_status 근거를 남긴다.

## 범위 밖

- 구현 코드 수정, API·백엔드·DB, AuthLayout 재디자인.

## 파생 경위
