## 목표
마켓 목록이 5천 대량에서 매초 전체 리렌더로 잰더나는 문제를 해소한다. reviewer minor-1(FC-100, 게이트3 비차단) 후속.

## 배경
- `MarketPage`가 `useNow`(1초 인터벌) 구독 → 누적된 전 `ShopCard` 매초 재조정(ShopCard memo 없음). 무한스크롤로 DOM은 스크롤 범위로 제한되나, 깊게 스크롤 시 수천 카드가 매초 리렌더.
- 마켓 카드는 **카운트다운 없음**·골드포스는 일 단위 → per-second now가 애초에 불필요.

## DoD (착수 시 확정)
- `ShopCard` `React.memo` + per-second `now`를 마켓 카드에서 제거(또는 goldforce 활성 카드에만 전달). 필요 시 리스트 windowing/가상화 검토.
- 5천 시드 상태에서 깊은 스크롤 시 잰더 없음 실측. 경매 목록(카운트다운 필요)엔 영향 없게.
