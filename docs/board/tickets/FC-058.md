## 목표
**첫 실화면을 만든다.** 지금 전 라우트가 placeholder라 볼 것이 없다.
`ItemArtSlot`을 함께 이식해 **아이템이 실물로 보이게** 한다.

## ★ FC-062를 흡수한다 (에픽 조정)
에픽 원안은 아트를 마지막(FC-062)에 뒀으나 **§5.12 골드포스 아웃라인·Game-Color Containment가
전부 폐기**되면서 그 티켓에 **남은 것이 아트 경로 로직 이식뿐**이 됐다.
그리고 아트가 마지막이면 **홈·경매·인벤토리가 전부 "Lv.N" 텍스트**로 나온다 — 또 "볼 게 없다"가 된다.
→ **FC-058이 아트 기반을 함께 만든다. FC-062는 폐기.**

## 이식할 것 (구 프론트 `05b5e1b`)
```
git show 05b5e1b:frontend/src/features/item/lib/itemArt.ts
git show 05b5e1b:frontend/src/features/item/lib/itemCode.ts
git show 05b5e1b:frontend/scripts/sync-game-art.mjs
```
- **아트 경로 규칙**: `/art/items/level{level}/{l|s}/{water|fire|earth|wind}/{kind}.png`
- **★ 레벨 축** — 우리 `level`은 **표시 레벨**이고 아트 디렉터리도 표시 레벨이다.
  **보정하지 마라.** 근거 `docs/spec/references/game-item-skill-format.md §2`.
  **틀리면 전 아이템이 한 단계씩 어긋난 그림으로 나가는데 눈으로는 거의 안 보인다** →
  **경로 생성 단위 테스트가 유일한 방어다.**
- `decodeTypeCode`(인벤토리 summary엔 `typeCode`만 온다) · **`kind`는 `subGroup` 종속**
- **미등록 코드 중립 폴백** + 코드 집합 크기 하드코딩 금지(계약 v1.10 §3.3.1 클라 의무)
- 마법은 `magic.png` 1장 — `kind` 1·2 공유
- `public/art` **gitignore 유지**(자산 정본은 `docs/game_ui`, 복사본은 미추적)

## ★★ 시각은 전부 템플릿
`ItemArtSlot`도 **템플릿 컴포넌트로 감싼다**(`Card` 등). 폐기된 것을 **부활시키지 마라**:
- ~~속성별 딥 글로우~~ · ~~골드포스 금색 아웃라인~~ · ~~element 4색 배지~~ · ~~Game-Color Containment~~
- **속성 배지는 템플릿 `Tag` 기본 색**을 쓴다.

**★ 그 결과 속성 간 색 구분이 사라진다**(같은 색 Tag 4종) → **라벨 텍스트 병기가 접근성을 넘어
기능적으로 필수**다(FC-057 파생 관찰). 속성을 **글자로 읽을 수 있게** 하라.

**아트 PNG 자체의 색은 이미지 내용물**이라 그대로 표시한다 — 주변에 색을 덧입히지 않을 뿐이다.

## 홈 구조 — 배치는 우리 몫 (FC-048 판단 계승)
- **홈은 "마케팅 랜딩"이 아니라 거래소 첫 화면**이다. **스크롤 0px에 실제 카운트다운** —
  카피로 주장하지 않고 **데이터로 증명**한다.
- 섹션마다 **구조 변주**(피처드·격자·행목록) — 같은 리듬 반복 금지.
- 시각(색·타이포·간격·컴포넌트)은 **전부 템플릿**.

## 쓸 API — 구현된 것만
| 섹션 | 엔드포인트 | 비고 |
|---|---|---|
| 마감 임박 | `GET /auctions?status=ACTIVE&sort=endAt,asc&size=5` | ✅ |
| 새 매물 | `GET /auctions?sort=createdAt,desc&size=8` | ✅ |
| 헤더 잔액 | `GET /me/balance` | ✅ (FC-057이 이미 함) |

**★ `/shops`(고정가)를 쓰지 마라 — 백엔드에 `ShopController`가 없다.**
FC-048이 계약만 보고 넣었다가 **홈에 에러 배너가 뜬 전력**이 있다. 계약에 있어도 **구현이 없다.**

**카운트다운은 `endAt` 파생**이다. 하드코딩 금지. 폴링하지 않으므로 "N초마다 갱신" 같은
**거짓 문구를 쓰지 마라**(FC-048 판단).

## 상태 설계 (FC-048 기준 계승)
- **로딩**: 데이터 무관한 부분은 **즉시 렌더** — 첫 화면이 백지가 되지 않게. 템플릿 `Skeleton` 사용.
- **빈 목록**: 자리를 지우지 말고 **다음 행동을 준다.**
- **에러**: **섹션별 격리** — 한 섹션이 죽어도 나머지는 산다.
