## 목표
- 탈퇴(SEC-006) 시 사용자의 refresh 세션을 전부 폐기하는 메서드를 `RefreshTokenStore`에 추가한다.

## DoD
- 사용자 단위 일괄 폐기, 원자적/멱등. 기존 회전·재사용 탐지 로직과 충돌 없음.
- 통합 테스트 그린. concurrency-review 스킬 참조(JWT/세션).

## 근거(인용)
> api-contract 2.5절 DELETE /me: soft delete + refresh 세션 전부 폐기(SEC-006 — 탈퇴 후 잔여 세션 접근 불가).

## 구현 메모 (FC-004 유의)
- `revokeAll(String userId)` = SCAN+DEL(멱등·논블로킹, 키 스킴 무변경). 엄격 단일-EVAL 원자성은 사용자 인덱스 신설 = 게이트2라 미채택.
- **호출 순서 제약**: SCAN은 스냅숏이 아니므로 탈퇴 서비스는 **user soft delete를 먼저** 하여 신규 세션 발급을 차단한 뒤 revokeAll을 호출해야 한다.
