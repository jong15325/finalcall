## 목표
- 경매 상세 화면을 만든다. **EPIC-BID 완료 시 입찰 UI가 얹힐 자리**를 미리 정확히 잡아둔다.

## DoD
- **라우트·페이지**: 경매 상세 페이지 신설(목록 카드 → 상세 이동). FC-036이 만든 컴포넌트(`ItemCard` 내부 요소·`Countdown`·`StatusChip`·`MoneyAmount`)를 **재사용**하라 — 중복 구현 금지.
- **API 연동**: `GET /api/v1/auctions/{auctionPublicId}`. 404(`AUCTION_004`) 처리.
- **표시 항목**(계약 §3.3 `AuctionDetail`): 아이템 스냅샷(이름·스탯·element)·시작가·즉시구매가(있으면)·남은 시간·판매자 닉네임·경매 상태·`minNextBidAmount`(계약 v1.8 F3 신설 — 종료 경매는 null).
- **★ 최고가·최고입찰자 영역**: 현재 `highestBidAmount`=null·`bidCount`=0·`highestBidderMasked`=null이다. **"입찰 없음 · 시작가 N"**으로 표시하되, **실값이 들어올 자리를 레이아웃상 확보**하라(EPIC-BID 완료 시 값만 채워지면 되도록). 값이 없다고 영역 자체를 없애면 나중에 레이아웃이 흔들린다.
- **입찰 CTA 자리**: 입찰 API는 EPIC-BID 소관이라 **동작을 구현하지 않는다.** 다만 §1.2대로 **블랙 CTA** 자리를 확보하고 `disabled` + "입찰 준비 중" 상태로 둔다(퍼플을 CTA 채움으로 쓰지 말 것 — 액센트 전용).
- **`ElementBadge`(§5.8)**: 소프트 틴트 배경 + near-black 라벨 + solid 도트. **흰 배경 위 텍스트 직접 사용 금지**(water 대비 2.37로 무너짐). 속성명 텍스트 병기 필수.
- **상태**: 로딩 스켈레톤 · 404 · 종료 경매(딤 + "마감/판매완료").
- **접근성**: `docs/ux/accessibility.md` 준수. 상세 진입 시 포커스 관리, Countdown `aria-live=off`.

## 금지
- 입찰 실행 로직·모달(§5.5)을 구현하지 마라 — EPIC-BID 완료 후 별도 티켓이다. **자리만 잡는다.**
- 디자인 시스템 밖 새 색·컴포넌트 금지. Game-Color Containment 준수.
- 백엔드(`backend/**`)·계약·spec·보드 수정 금지(EPIC-BID 병렬 진행 중).
