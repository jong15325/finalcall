## 목표
- 신규 대화 첫 메시지가 발신자 화면에 중복 표시되고 한 건이 `전송중`에 고착되는 문제를 수정한다.
- 초안 상대 프로필이 실제 채팅방 생성 후 올바른 상대 프로필로 즉시 수렴하도록 한다.
- 수신 메시지 도착 시 자동 스크롤이 중복 optimistic 메시지 때문에 방해받지 않도록 한다.

## DoD
- 첫 메시지 생성 요청과 `MESSAGE_CREATED` 이벤트가 하나의 메시지로 수렴한다.
- 서버에 실제 메시지가 중복 저장되는지 운영·백엔드 경로를 교차 확인한다.
- 신규 room 응답으로 상대 프로필과 메시지 상태가 즉시 정규화된다.
- 첫 메시지 수렴, 프로필 교체, 후속 수신 메시지 자동 스크롤을 회귀 테스트로 검증한다.

## 파생 경위
- FC-406 재배포 후 신규 대화 시작 경로에서 중복 optimistic 메시지와 프로필 불일치가 운영 재현되어 파생했다.
