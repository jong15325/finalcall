## DoD
1. **M1 (MePage 컨텍스트 clear)**: `MePage.tsx` 탈퇴 경로가 React 컴포넌트임에도 모듈 싱글턴 `resetSession()`을 쓴다. spec §4.3-a 원칙대로 **React 핸들러는 컨텍스트 `useQueryClient()`로 캐시 축출**하도록 정렬(AuthProvider의 방식 재사용). 프로덕션은 싱글턴=컨텍스트 동일 인스턴스라 기능 동일하되 원칙 일치·테스트 가능성 확보. **탈퇴 시 캐시 축출 단위 테스트 추가**(현재 부재).
2. **M2 (refresh 세대 가드 강화)**: `client.ts`의 stale-rotate 가드가 `refreshToken` 값 동일성 단독 의존이다. 이미 존재하는 `refreshEpoch`를 활용해 **세대(epoch) 기반 가드를 추가**(라인리지 + 세대 이중, 또는 세대 우선)해 값 동일성 의존을 제거·완화한다. 기존 T2/T3 회귀 유지 + 세대 가드 경로 테스트 보강.
3. 타입체크·lint·해당 테스트 통과. 전체 스위트 회귀 없음(기존 oauth env 실패 3건 제외).
