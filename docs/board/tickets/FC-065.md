## 목표
FC-058·FC-059가 각각 발견한 **템플릿 전역 결함 2건**을 한 티켓에서 처리한다. 둘 다 개별 화면의
문제가 아니라 **템플릿 컴포넌트 자체의 문제**라 화면마다 우회하면 우회가 N벌로 늘어난다.

## ★ 왜 묶었나
두 건 모두 **"화면 티켓이 우회로 넘긴 뒤 미처리로 남은 것"**이고, 해결책이 같은 질문
(**템플릿 원본을 고칠 것인가, 우리 쪽에서 감쌀 것인가**)으로 수렴한다. 따로 처리하면 같은
판단을 두 번 하게 된다.

---

## 결함 1 — `Button`이 `disabled`를 DOM에 전달하지 않는다 (접근성)

**총괄이 원본을 직접 열어 확인했다**(FC-058 보고를 그대로 옮기지 않았다).

`frontend/src/components/ui/Button/Button.tsx`:
- 59행 — `disabled`를 **구조분해로 꺼낸다** → `...rest`에 남지 않는다
- 77행 — `const unclickable = disabled || loading`
- 122·165행 — `opacity-50 cursor-not-allowed` **클래스만** 붙인다
- 195~201행 — `handleClick`이 `unclickable`이면 `preventDefault` 후 **조기 반환**
- 238~245행 — 렌더되는 `<Component>`에 **`disabled`도 `aria-disabled`도 붙지 않는다**

**결과**: **눈에만 비활성이고 보조기술에는 멀쩡한 버튼**이다.
- 스크린리더가 "비활성"을 **읽지 않는다** → WCAG **4.1.2 Name/Role/Value** 위반(상태 미노출)
- 키보드로 **포커스되고 활성화된다** → `handleClick`이 막으므로 **아무 일도 안 일어나는
  침묵의 무반응**이 된다. 사용자는 실패 이유를 알 수 없다
- `loading`도 같은 경로다(`unclickable`에 함께 묶임)

**현재 우회**: FC-058 캐러셀이 `aria-disabled`를 직접 얹었다(템플릿 무수정).

## 결함 2 — `ui/Checkbox` 배럴이 lodash를 끌고 온다 (번들)

`Checkbox.Group`이 `lodash/cloneDeep`·`remove`를 쓰는데 **배럴 임포트라 `Group.tsx`가 함께 딸려온다.**
**체크박스 한 개에 약 33 kB**이고, **메인 청크에 lodash가 없어 중복 제거가 아닌 순수 증가**다.

**실측**(FC-059): 목록 청크 **44.13 kB → 19.48 kB** (`ui/Checkbox/Checkbox` 직접 임포트로 회피).

**★ 다른 화면도 같은 값을 낸다** — 배럴을 쓰는 곳을 **전수로** 잡아야 한다. 화면이 늘수록 청크마다
반복된다.

## DoD
- **결함 1**: 비활성 버튼이 보조기술에 비활성으로 노출된다. `loading` 포함. 기존 `aria-disabled`
  우회(FC-058 캐러셀)를 **제거하거나 정본 경로로 흡수**해 우회가 남지 않는다.
- **결함 2**: `ui/Checkbox` **배럴 사용처 전수 조사** 후 처리. 처리 뒤 **화면별 청크 실측치**를
  before/after로 남긴다.
- 회귀 테스트 동반 — 비활성 버튼의 **접근성 상태**(단순 클래스 존재가 아니라 `disabled`/
  `aria-disabled` 속성)를 검증하는 케이스.
- `npm run test`·`typecheck`·`lint`·`build` 통과 + **번들 실측**.

## ★ 선행 판단 — 템플릿 원본을 고칠 것인가 (구현 전 결정)
이 에픽은 **템플릿을 원본대로 유지**하는 것을 전제로 왔다(FC-057이 `assets/styles/**`의 원본
diff 0을 확인해 뒀고, FC-058·059는 둘 다 **템플릿 무수정 우회**를 택했다). 그런데 두 결함은
**템플릿 내부에 있어** 우회로는 근본 해결이 안 된다.

세 갈래이고 **되돌리기 비용이 다르다** — 구현 착수 전에 고른다:
1. **템플릿 원본 수정** — 근본 해결. 대신 템플릿 업데이트 시 **충돌 지점이 생긴다**
2. **래퍼 신설**(`components/shared/`에 우리 `Button`) — 템플릿 무접촉. 대신 **임포트 경로를
   전수 교체**해야 하고 두 Button이 공존하는 동안 **어느 쪽을 쓸지 흔들린다**
3. **화면별 우회 유지** — 지금 상태. **결함 2는 화면마다 33 kB를 계속 낸다**
