## 목표
FC-042 목업(3차 확정안)을 실코드로 집행하고, **`ItemArtSlot`에 실아트를 매핑**한다.
경매 목록·상세는 이미 구현돼 있으나(FC-036·037) 목업 기준 **부채 18건 이상**이 식별돼 있다.

## ★ 이 티켓의 최대 가치 — 실아트
지금 `ItemArtSlot`이 전 화면에서 플레이스홀더("Lv.N" 텍스트)다. **FC-052가 시드를 아트와
짝맞춰 재작성**했으므로(템플릿 40종 전부 아트 보유) 이제 매핑이 가능하다.
`ItemArtSlot`은 **공유 컴포넌트**라 고치면 홈·목록·상세가 동시에 살아난다.

### 아트 경로 규칙
```
docs/game_ui/item_info/card_image/gold_black/level{표시레벨}/{l|s}/{water|fire|earth|wind}/
  {axe|wand|sword|bow|shield|pendant|armor|boots|magic}.png
```
- `l` 50×93(카드·상세) · `s` 26×28(행 썸네일) — **둘 다 세로형**
- 마법은 `magic.png` 1장 — `kind` 1·2가 **공유**한다(2:1)
- **레벨이 아트에 구워져 있다** → 웹이 `l`에 레벨을 중복으로 그리지 않는다(FC-042 판정)

### ★★ 레벨 축 주의 — 근거 `docs/spec/references/game-item-skill-format.md §2`
원게임 `itm_level`은 **0-based**(0 = 실제 1레벨)이나, **우리 `item_instance.level`은 표시
레벨(1~9)을 저장**한다. **아트 디렉터리도 표시 레벨**이다.
→ **우리 데이터에는 보정을 하지 마라.** `level{level}` 그대로다.
보정이 필요한 건 원게임 데이터를 이식할 때뿐이고 이 티켓 범위가 아니다.
**틀리면 전 아이템이 한 단계씩 어긋난 그림으로 나가고, 눈으로는 잘 안 보인다.**

### 자산 경로
목업은 `docs/ux/mockups/`에서 `../../game_ui/...`로 상대참조했다. **React는 `frontend/`
밖 파일을 번들할 수 없다** — 자산을 어떻게 서빙할지(public 복사 · vite 별칭 · 심볼릭 등)
**판단하고 근거를 반환하라.** 복사한다면 **무엇을 얼마나** 복사했는지 명시하라(전체 648장은 과하다).

## 집행할 목업 (3차 확정안)
`docs/ux/mockups/template-auction-list.html` · `template-auction-detail.html`

**확정된 구조** — 근거는 `docs/ux/references/auction-detail-references.md`:
- **데스크톱 = 안2**: 상단 가로 2열(아트 | 스펙) + 마감·입찰 전폭 + 입찰 이력 전폭 + 스티키 입찰 바
- **카드 클릭 = 아트 확대 라이트박스** (스펙 모달 아님 — Baymard "스펙 중심 상품에 퀵뷰 금지")
- **모바일 = 고정 하단 바**(현재가·잔여시간·CTA) + 입찰 시 **바텀시트**
- 타이포는 **역할 기반**(라벨 11 / 값 17 / figure 28 / figure-xl 44). **중간 크기 금지**
- 필터에서 **`kind`를 단독 축으로 그리지 마라** — `subGroup` 종속(계약 v1.10 §4.1 경고)

## ★ 반응형 별도 설계 (지속 원칙)
> 반응형은 배치 변경이 아니다. 웹은 웹, 모바일은 모바일에 맞게 짜여야 한다.

데스크톱·모바일 구조를 **각각 도식으로 제시**한다. 목업의 IA 대조표를 따른다 —
입찰 이력(표 ↔ 카드 리스트) · 입찰 입력(인라인 ↔ 바텀시트) · 마감(절대시각 ↔ 상대시간).

## ★ 알려진 제약 — 경매 데이터가 없다
FC-052가 시드를 확장했으나 **`item_instance`가 전부 `INVENTORY`이고 경매 시드는 없다.**
→ **경매 목록·홈이 실행 시 빈 상태로 나온다.** 이 티켓에서 백엔드를 건드릴 수 없으므로
**빈·로딩·에러 상태를 제대로 만드는 것**으로 대응하고(FC-048이 세운 기준을 따른다),
**시각 검증이 불가능하다는 사실을 반환에 명시**하라.
