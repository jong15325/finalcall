## 목표
- `themeStore` 기본 'dark' + `ThemeToggle`이 다크 CSS값 부재로 눌러도 변화 없는 비기능 컨트롤인 문제 해소.

## DoD
- U-005(다크값) 확정 전까지: 토글을 숨김/disabled 처리하거나 themeStore 기본값을 'light'로 정합(항상 라이트 렌더와 일치).
- 다크값을 지어내지 않는다(U-005 대기 규율 유지). typecheck/lint 그린.

## 파생 경위
- FC-016 리뷰 M2. 토큰 U-021 라이트 전환 후 `data-theme="dark"`가 붙어도 오버레이가 없어 항상 라이트 렌더 → 토글이 시각적 no-op. U-005 미래 인프라 대기라 범위 밖으로 분리.
