## DoD
- `POST /exchanges`: `Idempotency-Key` 헤더 필수(SEC-004) — 동일 키 재요청은 1회만 처리(재시도 안전). 요청 `{direction:"CASH_TO_GAME", cashAmount}`.
- 동작: 교환비율(1 캐시 = 1,000,000 게임머니, FC-007 확정 기전으로 조회·변경 가능) 적용 → **조건부 원자 캐시 차감**(가용 이내, FC-008 addCash 음수 방지) + 게임머니 지급(addGameMoney) + `applied_rate` 스냅샷 기록.
- 응답 201 `{gameMoneyAmount, appliedRate}`. 에러: EXC_001 캐시 부족(422), EXC_002 역방향 미지원(422, direction≠CASH_TO_GAME).
- 멱등키 이중 제출·재시도 무해. 통합 테스트(멱등·부족·정상). concurrency-review·jpa-convention·coding-discipline 준수. 빌드/테스트 그린.
