## 목표
고정가 판매자가 자신의 진행 중 리스팅을 조회하고 **내릴(취소)** 수 있는 UI를 제공한다. 백엔드 `POST /shops/{id}/cancel`·`markShopCancelledIfActive`·`releaseFromListing`은 FC-093에서 이미 구현됨 — **UI 소비처만 신설**.

## 배경 (EPIC-SHOP에서 분리)
- 게이트1 제품 결정에서 "판매 취소 허용" 확정. 백엔드는 구현 완료.
- 그러나 사용자 game-market 목업에 "내 판매 관리/내 리스팅" 화면이 없어(§9는 구매 측), UI 소비처 부재.
- 게이트 결정(2026-07-22, 사용자): **후속 티켓으로 분리**. EPIC-SHOP done을 막지 않음.

## DoD (착수 시 확정)
- 내 고정가 리스팅 목록(진행 중) 조회 + 개별 "내리기"(cancel) 액션 → `POST /shops/{id}/cancel`. 성공 시 인벤 회수 반영·목록 무효화.
- 화면 위치·디자인은 **디자인 게이트 선행**(목업에 없는 신규 화면 — 마이페이지 판매관리 탭 or 마켓 내 리스팅). 새 화면 착수 전 사용자 승인.
- 취소 불가 상태(이미 판매·만료) 문구·동시성 처리.

## 파생 경위: EPIC-SHOP FC-094 구현 중 cancel API UI 소비처 부재 발견. 사용자가 후속 분리 결정.
