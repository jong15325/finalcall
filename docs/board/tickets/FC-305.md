## 목표 / DoD

- 새 문서 성격의 SPA 페이지 전환은 이전 페이지의 스크롤 위치를 이어받지 않고 상단에서 시작한다.
- 같은 문서의 검색 조건 변경과 해시 이동, 브라우저 뒤로/앞으로 이동은 별도 정책으로 명시한다.
- React Router 선언형 모드에서 전역으로 한 번만 동작하도록 구현한다.
- 관련 단위 테스트와 프론트 타입 검사·lint를 통과한다.

## 근거인용

- 사용자 요청(2026-08-14): 페이지 이동 시 이전 스크롤 위치가 유지되는 현상을 레퍼런스에 맞춰 수정.
- React Router `useNavigationType`: 현재 이동이 POP/PUSH/REPLACE인지 구분한다.
- MDN `History.scrollRestoration`: 브라우저의 history 이동 스크롤 복원 정책을 애플리케이션이 제어할 수 있다.

## 확정 계약

- 최초 마운트와 POP 이동은 스크롤을 변경하지 않고 브라우저의 기본 위치 복원을 유지한다.
- PUSH/REPLACE로 pathname이 바뀔 때만 문서 상단으로 이동한다.
- 같은 pathname의 search/hash 변경은 같은 문서 내 조작으로 보고 현재 위치를 유지한다.
- pathname과 hash가 함께 바뀌는 새 경로는 pathname 전환 규칙을 우선한다.
- `/__design` 계열 전환은 워크벤치 검증 상태를 보존하기 위해 제외한다.
- 포커스 이동은 별도 접근성 계약 대상이므로 이번 변경에 포함하지 않는다.
