## 목표

기존 상세 콘텐츠 래퍼 내부 배경을 두 상세 라우트에 한정된 전체 뷰포트/AppShell 시각 배경으로 확장한다.

## DoD

- `/auctions/:id`와 `/items/:id` 마운트 중에만 fixed 장식 배경이 존재하고 이탈 즉시 정리된다.
- `body` dataset/class 및 이탈 후 남는 AppShell 전역 상태를 사용하지 않는다.
- 배경은 내비·콘텐츠·footer 아래, 모달·drawer·CompareBar·모바일 내비 아래에 머문다.
- 콘텐츠 래퍼에 모달을 가두는 z-index stacking context를 만들지 않는다.
- main/route에 overflow scroll container를 추가하지 않고 sticky 입찰과 body scroll-lock을 보존한다.
- 다른 라우트 직접 진입·상세 이탈·id 변경·로딩·에러·404 상태를 테스트한다.
- 기존 lazy load, 파일 크기, reduced-motion, forced-colors, 물 Canvas 중단·실패 폴백 계약을 유지한다.

## 범위 밖

- 목록 및 다른 라우트 배경, API·백엔드·DB, 상세 기능·정보 구조 변경.

## 파생 경위

FC-236 통과 후 사용자가 콘텐츠 래퍼 내부 배경의 이질감을 지적하고 v1.1 적용 경계 변경을 승인했다.
