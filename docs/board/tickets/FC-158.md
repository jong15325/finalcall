## 목표
소셜 로그인은 로그인·가입 통합(find-or-create)이라 회원가입 화면의 카카오·네이버 버튼이 잉여다. **회원가입 화면에서만** 소셜 버튼을 제거한다. **로그인 화면엔 유지**.

## DoD
- 회원가입 화면(SignupForm)에서 `SocialLoginButton`(카카오·네이버) 및 관련 구분선/문구 제거.
- 로그인 화면(LoginForm)의 소셜 버튼은 **불변**(제거하지 않음).
- 제거로 남는 레이아웃 공백·구분선("또는" 등) 정리 — 회원가입 폼이 어색하지 않게.
- `SocialLoginButton` 공용 컴포넌트 자체는 삭제하지 않는다(로그인이 사용).
- `npm run build`·lint 그린. 커밋 금지(총괄이 승인 후 커밋).

## 근거인용
FC-155(로그인·회원가입 양쪽 배선). 사용자 피드백: 소셜=로그인·가입 통합이라 회원가입 버튼 잉여. HANDOVER 2026-07-30 B.2.
