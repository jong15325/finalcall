## 목표

댓글 UI에서 사용하지 않는 비추천·스레드 접기 조작을 제거하고 모바일 작성자 메타를 한 줄로 정돈한다.

## DoD

- 루트 댓글과 답글 모두 공감 버튼·카운트는 유지하고 비추천 버튼·카운트는 화면에 노출하지 않는다.
- API 타입·쿼리 캐시·백엔드의 `DISLIKE` 호환 처리는 변경하지 않는다.
- 모바일에서 작성 시간을 작성자 닉네임 오른쪽 같은 행에 표시하고 별도 시간 행을 제거한다.
- PC에서도 기존 작성 시간과 `수정됨` 표시를 유지한다.
- 모바일·PC 모두 `답글 N개`/`접기` 토글을 제거하고 답글이 있으면 스레드를 항상 표시한다.
- 답글 로딩·오류 재시도·offset `답글 더 보기`·답글 작성·멘션 기능을 유지한다.
- 비추천·접기 버튼 부재, 작성자+시간 노출, 답글 즉시 표시를 프론트 테스트로 검증한다.
- 관련 테스트·lint·typecheck·production build가 통과한다.

## 근거인용

- 사용자 요청(2026-08-07): 댓글 비추천 삭제, 모바일 작성 시간을 아이디 우측으로 이동, 댓글 접기 기능을 모바일·PC 모두 제거.
