## 목표
실코드를 정본에 맞춘다. **현재 실코드는 정본보다 3버전 뒤처져 있다** — `index.css`·
`tailwind.config.js`에 **v0.5 토큰조차 안 들어갔다**(정본 v0.6.1). 이 티켓이 에픽 전체의 선행이다.

## 반영 대상 (design-system v0.6.1)
- **§2.1 표면 층 4단** — `bg #F7F7F8` / `surface #FFFFFF` / `surface-band #EFEFF1`(신설) /
  `surface-sunken #E8E8EB`. 종전 순백 3중복 폐기.
- **§2.2 조작 계층** — CTA 블랙(`ink`) · 퍼플 액센트 · `primary-disabled` + **`text-disabled`**.
- **§2.4 텍스트 램프** — `text-subtle #67676E`·`border-strong #818187`(v0.4 재계산값) +
  **`text-disabled #5F5F66`**(v0.6.1 신설).
- **§2.7 아트 슬롯 딥 글로우** — 속성별 방사 글로우(물·불 확정, 흙·바람은 FC-042가 §2.7 파생
  공식으로 도출). 종전 `surface-slot` 단일 검정 폐기.
- **★ §3 역할 기반 타입 스케일 7단** — `text-label`(11/700/+.12em) · `text-micro`(12) ·
  `text-body`(13) · `text-value`(17/−.02em) · `text-figure`(28) · `text-title`(34) ·
  `text-figure-xl`(44). **종전 `text-xs`~`text-3xl`은 전량 폐기다.**
- **§2.6이 핸드오프 정본**이다 — 매핑 표와 CSS 드롭인 블록을 그대로 쓴다.
  문서가 스스로 *"정의 절과 어긋나면 여기가 정본"*이라 규정한다.

## DoD
- `tailwind.config.js` `theme.extend`가 §2.6 매핑 표와 일치한다.
- `index.css` CSS 변수가 §2.6 드롭인과 일치한다.
- **폐기 토큰(`text-xs`~`text-3xl`)을 참조하는 기존 코드를 전수 조사**하고 역할 기반 토큰으로
  치환한다. **FC-045가 식별한 21개 역할의 흡수처(14/15/16 → 13 또는 17)가 작업지시서다.**
- 빌드·타입체크·lint 통과(`npm run build`·`typecheck`·`lint`).
- **치환으로 시각이 바뀐 화면을 목록으로 보고**한다(폐기 토큰을 쓰던 화면은 크기가 실제로 바뀐다).
