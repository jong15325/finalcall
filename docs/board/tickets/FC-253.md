## 목표

모든 AppShell route에 승인된 outer gutter와 mobile부터 구분되는 single white content frame을 적용한다.

## DoD

- main gutter를 기본 `px-3 py-4`, sm `px-5 py-5`, xl `px-8 py-7`로 고정한다.
- single plane은 max 1440px, mobile `rounded-xl border shadow-sm`, xl `rounded-2xl`을 사용한다.
- 상세 viewport 이미지·particle이 plane 바깥 gutter에서 유지되고 경매 상세 모든 콘텐츠는 plane 안에 있다.
- page-level white wrapper를 추가하지 않고 기존 FinalCall card·CTA를 보존한다.
- plane에 overflow/transform/filter/z-index stacking context를 만들지 않는다.
- 320px CTA/input, loading·error·404, sticky·modal·body scroll-lock·MobileBottomNav padding을 테스트한다.
- 일반 AppShell route와 상세 두 route의 동일 geometry 및 AuthLayout 무변경을 검증한다.

## 범위 밖

- API·백엔드·DB, 카드 정보 구조·CTA 의미 변경, AuthLayout.

## 파생 경위

FC-252 이후 사용자가 공통 plane의 배경 노출 gutter와 mobile frame geometry를 명시 승인해 파생됐다.
