## 목표

경매 상세의 뒤로가기·카드·입찰·이력을 배경과 분리된 하나의 불투명 white content region 안에 둔다.

## DoD

- 성공 화면의 `ElementDetailBackground` children 전체를 opaque `bg-surface` region 하나로 감싼다.
- 뒤로가기·toast·Hero·BidPanel·BidHistory가 region 안에 있고 dialog portal/fixed 동작은 보존한다.
- region은 responsive padding/radius/border/shadow를 가지며 viewport 이미지·particle과 outer gutter를 유지한다.
- region에 overflow/transform/filter/z-index stacking context를 만들지 않는다.
- 경매 내부 `.detail-surface` dark/glass 재정의를 제거하고 밝은 surface·기본 text/line·가벼운 계층으로 전환한다.
- 기존 정보 구조·금전 동작·orange CTA·sticky·modal/focus/body scroll-lock을 보존한다.
- loading·error·404도 동일 boundary·폭·padding을 사용하고 320px·200% 확대를 통과한다.
- `/items/:id`와 다른 route의 DOM·surface·theme은 변경하지 않는다.

## 범위 밖

- 아이템 상세·다른 route 재디자인, API·백엔드·DB, 경매 정보/CTA 의미 변경.

## 파생 경위

FC-254 이후 사용자가 AppShell plane만으로 부족하다고 명시하고 경매 상세 내부 white region을 승인해 파생됐다.
