## 목표
아이템 마켓에서 아이템 클릭 시 상세 페이지 이동 대신 **게임 카드정보(CARD INFO) UI를 차용한 패널로 목록에서 바로 구매**하는 화면의 **HTML 목업**을 만든다. 디자인 게이트 제출물 — 실 React 구현 아님(HTML/CSS/약간의 JS로 인터랙션만 시연).

## 참조·현황 (먼저 파악)
- **참조 이미지**: `docs/game_ui/card_info/카드정보-특수스킬.png` — 다크블루 패널·S랭크 뱃지+카드 썸네일·속성 테이블(타입·명칭·채널제한·속성·골드포스)·탭(기본특징/능력수치/특수스킬/합성경간)·스킬 목록·하단 액션 버튼. 이 구조/aesthetic을 차용.
- **현 마켓**: `frontend/src/pages/MarketPage.tsx`(목록)·`MarketDetailPage.tsx`(현 클릭 이동 대상)·`features/shop/components/{ShopCard,ShopBuyPanel,ShopPurchaseDialog,ShopHeroCard}.tsx`. 리스팅 데이터 타입(shop DTO)·게임 카드 자산(`docs/game_ui/`)을 확인해 실제 필드로 채운다(명칭·레벨·속성·스킬1/2·specSnapshot·판매자·가격).
- **구매**: `POST /shops/{id}/purchase`(즉시 구매·게임머니 차감). 목업에선 실호출 없이 구매 버튼·확인·성공/실패(잔액부족 SHOP_005 등) 상태만 시연.

## DoD
- `docs/ux/mockups/market-quickbuy-cardinfo.html` 생성. 마켓 목록(카드 그리드) + 아이템 클릭/구매버튼 → **카드정보 스타일 구매 패널**(모달 권장) 오픈 → 속성·특수스킬·가격·**구매 버튼**·확인 흐름을 한 파일에서 시연.
- **웹/모바일 별도 레이아웃**([[responsive-separate-design]]) — 모바일에서 패널이 안 깨지고 구매 버튼 접근성 유지.
- **디자인 게이트 3결정을 시각적으로 제시**: (1) 모달 vs 인라인(권장안 하나를 주로 보여주되 대안 언급) (2) 게임 다크패널 충실 vs 앱 커머스 톤 적응 (3) 상세페이지 대체. 목업은 **권장안(모달·카드정보 충실 차용·네비 대체)** 을 주로 렌더하고, 판단 근거를 파일 상단 주석/총괄 보고에 남긴다.
- 브라우저에서 렌더 가능(자기완결 HTML/CSS, 외부 의존 최소). 헤드리스 Chrome로 **웹/모바일 스크린샷 캡처**(총괄이 사용자에 제시할 수 있게).
- 앱 브랜드 토큰(네이비/골드/오렌지)과의 관계를 고려하되, 사용자가 게임 aesthetic 차용을 명시했으므로 게임 카드 톤을 주로 반영.
