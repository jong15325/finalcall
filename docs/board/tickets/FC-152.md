## 목표

## DoD (산출 = spec 문서 확정안 + 게이트2 상신용 요약)
- **api-contract §2 확장**: `POST /api/v1/auth/oauth/{provider}`(provider=naver|kakao). 요청 = 프론트가 받은 `{ code, state?, redirectUri }`. 응답 = **기존 `LoginResponse` 형상 그대로**(`accessToken`·`refreshToken`·`accessExpiresAt`) — 형상 보존. 에러코드(잘못된 code·provider 오류·state 불일치 등) 정의.
- **erd/스키마**: `user_social_account`(id·user_id FK·provider·provider_user_id·created_at, **UK(provider, provider_user_id)**) 신규. `user.password_hash` **nullable화**(소셜 전용 계정). Flyway 버전 = V19(현재 최신 확인).
- **결정 3건 반영**: ①로그인·가입 통합(엔드포인트 하나가 find-or-create) ②이메일 자동연결 안 함(provider+id가 신원 키, email은 프로필) ③닉네임 충돌 시 유니크 접미사 규칙 명세.
- **보안 정합**: SEC-007(소셜 계정 존재 여부·자동가입이 열거 벡터 안 되게) · state/CSRF 파라미터 정책 · X-Gateway-Token(콜백 API가 게이트 경유) 서술.
- **게이트2 상신 요약**: 스키마 변경·계약 신설을 평이한 언어로 정리(사용자 승인 대기). 승인 전 구현 팬아웃 금지.
