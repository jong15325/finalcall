## DoD (착수 시 확정)
- **CDC 라이브 동기 end-to-end 검증**: finalcall-mysql을 binlog 옵션으로 재생성(현재 compose 밖 컨테이너라 미적용) → Debezium source·Aiven ES sink 등록 → MySQL 변경(등록·구매·상태전이)이 ES에 근실시간 반영되는지 실측. 현재는 부팅 재색인만 검증됨.
- **화해 완전화**: SearchReconciliationWorker의 count → **count + price/status histogram** 대조(reviewer FC-109 minor). 상태전이 드리프트 탐지.
- **운영 초기색인 전략**: local만 reindex-on-startup·correct-on-drift on. **운영은 트리거 없음** → 대량 재색인 배치/온디맨드 재색인 API/alias 스위치 절차 확정(FC-107 backend-impl 후속 명시).
- **ES sink 버전 정합**: Aiven 7.17 클라 vs ES 8.18.8 서버 typeless bulk 동작 확인(런타임 거부 시 sink 커넥터 버전 상향).
- **관측**: CDC lag·화해 드리프트 메트릭/로그.
