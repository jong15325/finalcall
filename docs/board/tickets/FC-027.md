## 목표
- 경매 목록(cursor)·상세 조회 API를 구현한다. 입찰 미구현이라 최고가·최고입찰자는 null/0 처리.

## DoD
- **목록 API** `GET /api/v1/auctions`(인증 불요): 공통 목록 필터 + cursor 페이지. 응답 = 경매 요약 + item 표시 스냅샷. 정렬 화이트리스트(price·endAt·createdAt·highestBidAmount).
- **상세 API** `GET /api/v1/auctions/{auctionPublicId}`(인증 불요): 경매 상세 + item 스냅샷. **lazy 활성화 파생**(status SCHEDULED 영속·startAt≤now면 응답 ACTIVE 파생). 최고가=null·bidCount=0·highestBidderMasked=null(게이트2 b). 남은 시간. 없음 AUCTION_004(404).
- **구현**: `api/auction/`(AuctionSummaryResponse·AuctionDetailResponse·AuctionItemView) + AuctionService·AuctionRepositoryCustom/Impl(QueryDSL 필터·cursor)·SearchCondition·Cursor·Slice 편집/추가.
- **테스트**: 목록 필터·cursor·정렬, 상세(lazy 활성화 파생·최고가 null·404) 슬라이스/통합. spotless·checkstyle 통과.

## 근거(인용)
> 계약 §3.1 "GET /auctions … cursor 페이지(경매 요약 + item 표시 스냅샷)", "GET /auctions/{id} … 상세 + 현재 최고가·최고입찰자(마스킹)·남은 시간". auction-domain-spec 게이트2 (a)(b).
