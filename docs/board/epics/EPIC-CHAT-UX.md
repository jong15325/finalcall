## 목표
- 긴 대화가 페이지 전체를 늘리지 않도록 대화 타임라인을 내부 스크롤 영역으로 고정한다.
- 상대 선택만으로 서버 방을 만들지 않고 첫 메시지 전송이 성공할 때만 상대방에게 대화방이 나타나도록 계약을 보정한다.
- 신규·미열람 방의 실시간 메시지가 방 선택 없이 목록과 타임라인에 즉시 반영되도록 한다.
