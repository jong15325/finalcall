## 휘발성 맥락 (파일에 없음 — 반드시 읽을 것)

1. **동적 실행 불가는 구조적 제약이다.** 이 환경은 Docker 미가용·Java 11(프로젝트 21) → Testcontainers
   구동 불가. 총괄 확인분(096): "일시적 문제가 아니라 구조적 제약, D-078 설계와 정합, **동적 실행은
   항상 손 배정**". **다음 세션이 `./gradlew test`를 시도하지 말 것** — 시간만 버린다.
2. **Glob 도구가 실재 파일에도 `No files found`를 반환한다**(이 세션 전 구간 재현). 파일 탐색·목록은
   **Grep + Read**로 할 것. D-090이 호스트 도구를 정본이라 하나 Glob은 이 환경에서 신뢰 불가.
3. **bash 마운트 뷰는 stale을 에러 없이 서빙한다**(D-090). 판단 근거 금지. bash 허용분 = 테스트·빌드
   실행, git 오브젝트 조회(`git log`·`git show`는 정확), docker/java 가용성 확인.
4. **총괄이 반복해 값으로 인정한 QA 처신 3가지** — 이게 이 역할의 실질이다:
   (a) **지시받지 않은 자문**("그 기준으로 통과시킨 것 중 또 뭐가 새는가" → V3 erd 전항목 재대조),
   (b) **증거 출처·한계 자진 명시**(실행 못 했으면 못 했다고 쓰고, 그럼에도 판정하는 근거를 따로 세움),
   (c) **뿌리 점검**(D-085) — 여기서 나온 게 D-089·test-plan 상시 규칙이 됐다.
5. **결함 vs RETEST 구분 감각**(Q-003 vs QA-001): 완료 **후** 계약이 바뀌어 생긴 새 요구 = RETEST(결함
   아님). **이미 있던** 확정 스펙 위반 = 결함. 이 선을 흐리면 결함 지표가 거짓이 된다.
6. **MBR-06이 유일한 검출 지점이다.** D-081 기각안 (a) `UNIQUE(자연키, deleted_at)`를 넣으면 재가입·
   재탈퇴 등 **MBR-01~05가 전부 초록이고 활성 중복만 조용히 열린다**. soft delete 자연키 도메인마다
   필수(test-plan 상시 규칙). API 경유 테스트는 선검사가 먼저 409를 던져 **무력** — DB 레벨 단언 필수.
7. **D-092 교훈(내가 밟았다)**: 근거 줄에 남의 문서 버전·목록·행 번호를 **전사하면 그가 상향할 때
   내 전사본이 낡는다**. 내 grep은 내가 상향할 때만 돈다. → **복제하지 말고 참조하라**(감시 대상 목록은
   erd [4] 말미 주를 가리키기만 함, QA-001은 행 번호 대신 절 참조).
8. 표기: 절 참조는 `§` 금지 → 대괄호 `[N.M]`(D-087, 앞으로만·소급 교체 금지). 신규 Q-xxx는 **`집행:`
   필드 필수**(D-089, 공란 금지). 부재·수량 주장은 **탐색 방법 1구 명시**(D-086).
9. **이의 제기는 의무다**(D-083). 총괄 지시가 진행 중 작업과 부딪히면 따르기 전에 말할 것. 다만 의무의
