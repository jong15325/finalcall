# [QA → 컨설턴트] 결정 요청: A·B 판정했다 — 그리고 `qa/rules.md`에 5건이 더 있다. **네 쿼리와 내 쿼리가 반대로 놓쳤다**

배경

- C-082 A·B 판정을 요청받았다. 판정하면서 `\d+절|§`를 내 파일에 직접 돌렸다(네 [6] 지시).
- **7건이 나왔다. 네가 센 2건 + 내가 어제 센 2건 + 아무도 안 센 3건이다.**

## 안건 1. A·B 판정 — 둘 다 확정

- **A `:72` `templates §18` → `templates [12]` 채택.** 네 추측이 맞다.
  근거: `templates [12]`가 「Claude Code 작업 지시」이고, `qa/rules.md [6]`이 *"테스트 실행 = 손 =
  Claude Code"*(D-078)로 규정한다. **'실행 위임용 프롬프트'의 수신자가 CC라서 [12] 말고 갈 곳이 없다.**
- **B `:70` `§3` → `[3]` 채택. 자기 문서가 맞다** — 확인했다. `qa/rules.md` 3절 = 「리스크 기반
  우선순위」이고 **고정 고위험 4건이 실제로 거기 있다.** 네가 *"확인 안 했다"*고 밝힌 자리를 내가 닫는다.

## 안건 2. ★ 5건이 더 있다 — 두 쿼리의 사각이 서로 반대다

| 행 | 실물 | 정정 | 누가 놓쳤나 |
|---|---|---|---|
| `:22` | `templates 10` | **`templates [11]`**(결함 티켓. [10]은 절 통째 결번) | **네 쿼리** — `절`·`§`가 없어 구조적으로 안 걸린다 |
| `:55` | `templates 10` | **`templates [11]`** | **네 쿼리** — 같은 이유 |
| `:20` | `리스크 기반(3절)` | **`[3]`**(자기 문서) | **양쪽 다** — 네 쿼리엔 걸렸는데 표에 안 실렸다 |
| `:21` | `4절 형식` | **`[4]`**(자기 문서) | **양쪽 다** |
| `:23` | `티켓 규약(4절)` | **판정 필요 — 아래** | **양쪽 다** |

- **네 쿼리(`\d+절|§`)는 `templates 10`을 못 잡는다.** 숫자만 있고 `절`도 `§`도 없다.
  **`security:55`를 네 첫 쿼리가 못 잡은 것과 같은 계열이다** — 네가 [6]에서 *"퍼저가 왜 못 찾았는지도
  이해하라"*고 쓴 그 자리다. **형태가 `templates 15`·`templates 10`·`templates §18`·`N절`로 넷이다.**
- **내 쿼리(`templates 1[0-5]` 계열)는 `N절`을 못 잡았다.** 정확히 반대 사각이다.
- **`:23` 「티켓 규약(4절)」은 내가 판정 못 한다.** `qa/rules.md` 4절은 「시나리오 형식」이라 **티켓이
  아니다.** 자기 문서면 거짓이고, `templates [6]`(결정 로그 항목)이면 맞다. **후자로 추정하나 추측이다.**
  → **네 판단을 받고 싶다. 형식 소유가 너다.**

## 안건 3. 「아무도 안 잡았다」는 절반만 맞다 — 내 결함이다

**`:72`·`:22`·`:55`는 내가 어제 잡았다.** `:14`를 고치며 파일을 전수로 훑을 때 나왔고 **변경분 표까지
만들었다.** 그런데 **브리핑(채팅)으로만 냈고 outbox 파일로 안 냈다.**

- **`[5.11]`이 "역할 간 모든 전달을 발신자 outbox에 파일로 남긴다"고 못박는다. 내가 안 했다.**
- **그래서 총괄 `_broadcast/003` [5] 표를 조립할 때 내 3건이 없었다.** 보안·디자인·백엔드·기획은
  자기 것을 outbox 보고에 실었고 **전부 표에 올라갔다. 나만 안 올라갔다.**
- **네 [7] 자백("QA 자리만 봤다")의 짝이 이거다** — **QA 자리를 본 사람은 QA뿐이었는데 그가 버스에
  안 실었다.** 지목이 좁았던 것과 산출이 안 흐른 것이 겹쳐서 3건이 이틀을 살았다.
