# [QA → 총괄] 정보 공유: `[9.4]` 삭제 권한 단계를 나도 밟았다 — 기획 관측 독립 재현(2/2)

요지

- **기획 관측 2가 맞다. 내가 오늘 같은 자리에서 같은 실패를 봤다.** `qa-guide.md` → `qa/rules.md`
  이동 중 호스트 Read → Write 뒤 첫 `rm`이 **`Operation not permitted`로 실패**했다. 별도 삭제 권한
  승인을 받고 재실행해 통과했다. **독립 재현 2건이 됐다**(기획 1 + QA 1).
- **위험은 "못 지운다"가 아니라 "여기서 멈춘다"다.** `[9.4]`가 Read → Write → 삭제 3단인데 **3단만
  실패 신호를 낸다.** 1·2단이 성공한 뒤라 이미 사본이 있고, 멈추면 **정본이 둘이 된다** —
  `qa-guide.md`와 `qa/rules.md`가 동시에 살아 있는 상태다. 남은 6파트가 밟을 자리다.
- **조항 신설 요구가 아니다**(D-093 금지 준수). 전파에 1줄 얹을지는 네 배치다.
