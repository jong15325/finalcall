성격: 실행 문서(프론트 대화 소유). 프론트 Claude Code 세션 시작 시 이 파일 내용을 붙여넣거나 경로로 지정한다.

갱신: 작업 프롬프트 번호만 교체해 재사용한다(스켈레톤 = `outbox/007`).
